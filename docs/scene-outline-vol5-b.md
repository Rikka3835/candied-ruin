## ch53 灶

**日**：第 21 日，午后到入夜｜**本章事件**：锅壁口见到埃利亚斯；他用盐霜试芙兰的舌头；陶片与锅壁刻字对上半个「钥」；他提出「要开锅，把舌头留在灶上」——钩是「整块不是糖，是锅的钥匙」。

**场 1**｜时间地点：第 21 日午后｜锅壁口·埃利亚斯的小灶
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、布伦丹、埃利亚斯
- 核心行动：布伦丹带他们穿过焦色碎石地，风变咸变硬。埃利亚斯蹲在土坯灶前，用刮刀刮石面上的盐霜，刮一下，闻一下，再刮。他抬头先看老塞，看了很久；再看芙兰的嘴，不看眼睛。
- 对话要点：
  1. 布伦丹→芙兰：「小舌头，船我给你留到后天。灯船那边，只等到明天午前。」
  2. 埃利亚斯→众人：「锅不等人。要进，现在进。」
  3. 老塞→埃利亚斯：「你是……灶边那个。」
  4. 埃利亚斯→老塞：「你的名字呢。」／老塞：「……记不全了。」
- 代价/钩：布伦丹的船期压到后天（回城的路开始计时）；老塞当众露了「名字不全」的底。

**场 2**｜时间地点：同日｜灶前石台
- 在场人：芙兰、埃利亚斯、琉玥、薇尔、老塞
- 核心行动：埃利亚斯舀一碗咸糖水给芙兰，很难喝。她抿一口，停三下。他问「哪一年的盐」，她答不出来——舌头只剩一格，尝到的只有咸和一点苦尾。她改口，用记下的味和看的：盐霜的苦尾像锅底刮下来的，边上新刮的痕是昨天的。埃利亚斯听完，把碗收走，说「锅在动」。
- 对话要点：
  1. 埃利亚斯→芙兰：「尝。别咽。」
  2. 芙兰：「咸。苦尾。像锅底刮下来的。」
  3. 埃利亚斯：「哪一年。」
  4. 芙兰：「去年的盐，前年的锅。你昨天刮过一遍，边上那道痕是新的。」
  5. 埃利亚斯：「锅在动。」（他认了她）
- 代价/钩：她第一次靠「记＋看」补舌头的缺；埃利亚斯承认她还能用。

**场 3**｜时间地点：同日，日头偏西｜灶边·刻字墙
- 在场人：芙兰、埃利亚斯、老塞、薇尔、琉玥
- 核心行动：芙兰把陶片放在刻字墙前比对：陶片上的半个字和墙上被刮开的刻字是同一笔法，浅口、斜刀。埃利亚斯用指甲把两个字中间那道盐霜刮掉，两个半边合起来是一个「钥」。薇尔伸手要记，埃利亚斯把她的手挡开。
- 对话要点：
  1. 芙兰→埃利亚斯：「陶片上的半个字，跟锅壁上的是一个。」
  2. 埃利亚斯：「『钥』。一半在这儿，一半在锅里。」
  3. 薇尔：「规矩是——这个字不能写进册子。」
  4. 埃利亚斯→老塞：「你带来的，是雅各布尝过的那种舌头。」
- 代价/钩：半个字合成「钥」；薇尔被禁止记——她偏偏记住了（伏笔）。

**场 4**｜时间地点：同日，黄昏｜灶前
- 在场人：芙兰、埃利亚斯、琉玥、老塞、薇尔
- 核心行动：埃利亚斯把刮刀插进灶膛边，说开锅要留一样东西在灶上。琉玥先挡在芙兰前面；芙兰把她拨开，问「留什么」。埃利亚斯说「舌头」，又补一句：不是割，是尝完归锅，人还能走。芙兰说「留」。
- 对话要点：
  1. 埃利亚斯→芙兰：「要开锅，得留一样东西在灶上。」
  2. 芙兰：「什么。」
  3. 埃利亚斯：「舌头。尝完，舌头归锅，人还能走。」
  4. 琉玥：「不行。」
  5. 芙兰：「留。」
- 代价/钩：口头押舌（契）——ch54 兑现；琉玥第一次没拦住她。

**场 5**｜时间地点：同日，入夜前｜灶边·盐霜石
- 在场人：老塞、埃利亚斯、芙兰
- 核心行动：埃利亚斯把老塞叫到灶边，问他四十年前的事。老塞记得一个空位，不记得名字。埃利亚斯说「名字我先记着」，又低声告诉芙兰：他记得我的名字，我不记得你的了。芙兰没接话，把自己名字说了一遍，让他跟着念；他念到第二个字就停了。
- 对话要点：
  1. 埃利亚斯→老塞：「四十年前你也在。你记得第七位吗。」
  2. 老塞：「记得一个空位。」
  3. 埃利亚斯：「名字我先记着。」
  4. 老塞→芙兰（低声）：「他记得我的名字。我不记得你的了。」
  5. 芙兰：「芙兰。你再念一遍。」
- 代价/钩：老塞的名字债第一次摊开；埃利亚斯手里多了一个「记着」的名字（ch57 回收）。

**场 6**｜时间地点：同日，入夜｜锅壁口·豁口
- 在场人：芙兰、薇尔、柯林、布伦丹、琉玥、老塞
- 核心行动：布伦丹的人从滩上跑回来报：灯船放了两条小艇，白手套那个站在船头，说「按册收归」。薇尔把期限算给他们听：明天午前，交罐子、交人、交整块，三样里交一样就能谈；一样不交，灯船就靠岸。柯林要去引开小艇，被芙兰按住左手。
- 对话要点：
  1. 布伦丹：「灯船放小艇了。白手套那个，说要『按册收归』。」
  2. 薇尔：「明天午前。他给的是期限，不是价钱。」
  3. 柯林：「我去引开他们——」
  4. 芙兰：「你的手先养着。」
  5. 老塞：「他们不敢夜里上滩。」（他说完看了埃利亚斯一眼）
- 代价/钩：期限落到「明天午前」；布伦丹的船期与灯船期限开始对撞。

**场 7**｜时间地点：同日，夜｜灶膛前
- 在场人：芙兰、埃利亚斯、老塞、琉玥、薇尔
- 核心行动：埃利亚斯让芙兰把整块糖拿出来看。她从罐里取出半颗，老塞从布袋里取出另半颗；两个断面平得像切过又磨过。埃利亚斯不接，只看，看完把刮刀插回灶膛，锅底「咕」了一声。他说出那句话。
- 对话要点：
  1. 埃利亚斯→芙兰：「你以为整块是糖。」
  2. 芙兰：「不是。」
  3. 埃利亚斯：「整块不是糖。是这口锅的钥匙。」
  4. 芙兰：「钥匙开什么。」
  5. 埃利亚斯：「开锅。也开人。」（他不解释第三样）
- 代价/钩：钩子落地——整块＝锅的钥匙（反转）；芙兰手里的半颗糖从此不是糖，是钥匙的一半。

**本章代价**：芙兰口头押出舌头（契，ch54 兑现）；陶片押在灶上（开门的定金）；老塞的名字债当众亮出；布伦丹的船期压到后天。
**钩型**：反转——「整块不是糖。是这口锅的钥匙。」
**章末落点**：他把刮刀插回灶膛，锅底「咕」了一声，像有人应了一句。
**阶／格露头**：芙兰「只剩一格」由她自己说一次（全章 1 处）；不报数值对撞。

## ch54 尝

**日**：第 22 日，午前到午后｜**本章事件**：两颗糖合成整块；芙兰尝出「锅」的形状；最后一格清零、彻底失味；失味之后她反而听见了底下的话。

**场 1**｜时间地点：第 22 日，午前｜灶前石台
- 在场人：芙兰、老塞、埃利亚斯、琉玥、薇尔、柯林
- 核心行动：两个半颗在石台上合拢，断面咬合，严丝合缝。埃利亚斯用盐霜洗过手，把整块翻了个面，让芙兰看断面上那道细纹：像锅底的一圈旧裂。薇尔在册上写「整块，一颗」，写完把笔停住。
- 对话要点：
  1. 芙兰：「你半颗，我半颗。断面平。」
  2. 老塞：「合上。别让它掉地上。」
  3. 埃利亚斯：「锅不等人。合上就尝，尝完就开门。」
  4. 薇尔：「我记：整块，一颗。第 22 日。」
- 代价/钩：整块第一次合拢；薇尔把这一笔记在册上（后面所有人都会来查这一页）。

**场 2**｜时间地点：同日｜灶前
- 在场人：芙兰、琉玥、老塞、埃利亚斯
- 核心行动：琉玥拦在石台前，说只剩一格，尝完整块就一点不剩。芙兰把银匙从她手里拿下来，放回她掌心，说自己数过了。老塞站在她身后，说「你尝，我记着」——他已经叫不出她的名字，只叫「你」。
- 对话要点：
  1. 琉玥：「你现在只剩一格。」
  2. 芙兰：「一格也是尝。」
  3. 琉玥：「尝完就没了。」
  4. 芙兰：「那就尝完。」
  5. 老塞：「你尝。我记着。」
- 代价/钩：尝＝清零，全队都知道，没人再劝（琉玥把银匙收进袖子）。

**场 3**｜时间地点：同日，正午｜灶前石台
- 在场人：芙兰、埃利亚斯、琉玥、薇尔、老塞、柯林
- 核心行动：芙兰咬下一小角整块，含住，停三下，咽。她闭眼报味：甜是旧的，咸在甜底下，铁在咸底下，最底下是一层火。她说出形状：圆的，没有边，底是黑的。埃利亚斯追问「锅在等什么」，她答「等一个人尝完」——说完她自己愣住。
- 对话要点：
  1. 芙兰：「甜是旧的。咸在甜底下。铁在咸底下。」
  2. 芙兰：「圆的。没有边。底是黑的。」
  3. 埃利亚斯：「再说一遍。锅在等什么。」
  4. 芙兰：「锅在等一个人尝完。」
  5. 琉玥（低声）：「她看见锅了。」
- 代价/钩：整块的第一层被尝开；芙兰报出「锅」的形状（信息，但只有她一个人看见）。

**场 4**｜时间地点：同日，午后｜灶前
- 在场人：芙兰、琉玥、埃利亚斯、薇尔、柯林、老塞
- 核心行动：琉玥把三样东西摆在她舌上：糖、盐、苦盐霜。芙兰分不出，说「都一样」。琉玥又递银匙，让她说匙上是什么；她说「不知道」。琉玥把银匙放下，说「你尝完了」。芙兰坐着没动，伸手摸自己的舌头，像确认它还在。
- 对话要点：
  1. 琉玥（递银匙）：「这是什么。」
  2. 芙兰：「……不知道。」
  3. 琉玥：「再试。糖、盐、苦。」
  4. 芙兰：「都一样。」
  5. 琉玥：「你尝完了。」
- 代价/钩：最后一格清零，彻底失味（本章主账落地）；她摸舌头，舌头还在，味没了。

**场 5**｜时间地点：同日，午后｜灶边
- 在场人：芙兰、琉玥、薇尔、老塞
- 核心行动：芙兰坐了一会儿，开口定下补偿的法子，一条一条说：一，琉玥替她尝第一口，她问「甜、尾、挂不挂勺」三样；二，她把自己尝过的味背成词条，薇尔替她记；三，看断面、看光、看丝，不看舌头；四，凡拿不准的，用火候和时辰算。薇尔在册子新起一页，页头写「芙兰的味」。
- 对话要点：
  1. 芙兰：「从今天起，你替我尝第一口。我问三样，你答三样。」
  2. 琉玥：「哪三样。」
  3. 芙兰：「甜、尾、挂不挂勺。」
  4. 薇尔：「我记。这一页叫『芙兰的味』。」
  5. 琉玥：「要是我也尝不出呢。」
  6. 芙兰：「那就看。看断面，看光，看挂不挂得住。」
- 代价/钩：补偿四件（问、记、看、算）立起来；薇尔的册子从此多一页——她的舌头变成了别人的账。

**场 6**｜时间地点：同日，黄昏｜灶眼·壁前
- 在场人：芙兰、埃利亚斯、老塞、琉玥
- 核心行动：失味之后，芙兰把耳朵贴在灶眼边的壁上。熬声比之前清楚：一勺、一勺，中间夹着一个很轻的词。她听清后脸色变了，说出来。埃利亚斯第一次把手里的刮刀放下。
- 对话要点：
  1. 芙兰（贴壁）：「底下有人说话。」
  2. 埃利亚斯：「你听见什么。」
  3. 芙兰：「……别尝。」
  4. 老塞：「它在跟你说话。」
  5. 埃利亚斯：「它从来不跟人说话。」
- 代价/钩：钩子落地——失味之后她反而听见了底下的话（信息）；埃利亚斯第一次失态。

**场 7**｜时间地点：同日，夜｜灶眼·缝口
- 在场人：芙兰、埃利亚斯、老塞、琉玥、薇尔、柯林
- 核心行动：埃利亚斯把灶眼后的一扇糖壳门推开一道缝，说下去只有这一条缝，侧身过，走半天。芙兰问自己的舌头，他指指灶台，说「在灶上」。他把陶片收进围裙口袋，说「名字我先记着」。缝里吹出的风是热的，带着熬糖的甜。
- 对话要点：
  1. 埃利亚斯：「灶门开了。下去只有一条缝。」
  2. 芙兰：「我的舌头呢。」
  3. 埃利亚斯：「在灶上。名字我先记着。」
  4. 老塞：「明天午前，灯船。」
  5. 埃利亚斯：「锅不等人。你们的账，自己算。」
- 代价/钩：舌头押在灶上（契兑现）；陶片归埃利亚斯；下锅壁内侧的门开了，但灯船期限只剩半天。

**本章代价**：最后一格清零、彻底失味（不可逆）；陶片押在灶上；芙兰的「尝」改为问／记／看／算；灯船期限剩半天。
**钩型**：信息——失味之后她反而听见了底下的话（「……别尝。」）。
**章末落点**：缝里吹出来的风是热的，甜得发闷；她站在缝口，第一次闻不出那是什么甜。
**阶／格露头**：琉玥说「一格」「清零」两次（全章 2 处）；之后不再报格。

## ch55 描名

**日**：第 23 日，上午到午后｜**本章事件**：薇尔被请上灯船核册；克劳斯开价；尤金承认自己就是描名的人（三层铅笔描痕对上 ch40）；薇尔拒绝用「伪造」换回名字；钩是「描名的人，下一个就是你」。

**场 1**｜时间地点：第 23 日，上午｜盐场外海·灯船
- 在场人：薇尔、芙兰、克劳斯、索恩、尤金
- 核心行动：小艇把薇尔和芙兰接上灯船。舱里点着四盏灯，克劳斯坐着，白手套压在册子上；索恩站在门边，手背在身后；尤金坐在灯下抄册，先擦手，才翻页。克劳斯请薇尔坐，薇尔不坐，站着把册子摊开。
- 对话要点：
  1. 克劳斯→薇尔：「按册子来。你上船，我们核一页。」
  2. 索恩（门边）：「所长在里头。」
  3. 薇尔：「规矩是——核册要两个人看着。」
  4. 克劳斯：「另一个是你。」
- 代价/钩：薇尔进灯船（她的名字被摆上桌）；芙兰空着手，罐子留在岸上。

**场 2**｜时间地点：同日｜灯船舱
- 在场人：芙兰、薇尔、克劳斯、索恩、尤金

## ch56 熬

**日**：第 24 日，全天｜**本章事件**：下锅壁内侧；壁上刻字与陶片对上；柯林为推开薇尔被糖壳咬住左臂，手废；芙兰用问／记／看／算找路；底下那个东西「翻了个身」。

**场 1**｜时间地点：第 24 日，清晨｜锅壁口·缝口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、埃利亚斯、布伦丹
- 核心行动：埃利亚斯把缝口的两块糖壳撬开，只容一人侧身。他把三只盐霜小陶瓶分给芙兰两只、薇尔一只，说盐霜能试壁上的湿。布伦丹在豁口喊话：船留到后天，后天不来他走。埃利亚斯不下去，说「我守口」。
- 对话要点：
  1. 埃利亚斯：「缝只过一个人。侧着。」
  2. 芙兰：「你下去吗。」
  3. 埃利亚斯：「我守口。锅不等人。」
  4. 布伦丹：「船我留到后天。后天不来，我走。」
  5. 老塞：「够了。」
- 代价/钩：盐霜瓶（试湿／试路的工具）到手；船期从「后天」起算，倒数开始。

**场 2**｜时间地点：同日，上午｜锅壁内侧·窄道
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：缝里没有光，靠手摸。壁是温的，靠久了衣服发黏；说话会被吃掉后半句。柯林不信，说了一句，后半截被壁吸走，他立刻闭嘴。芙兰摸到壁上被刮开的刻字，用指甲顺着笔画走，认出和陶片同一种笔法。
- 对话要点：
  1. 薇尔：「说话只能半句。」
  2. 柯林：「为什——」（后半被吃）
  3. 琉玥：「先别说话。」
  4. 芙兰（摸壁）：「壁是温的。刻字在这儿。」
  5. 老塞（低声）：「别念。」
- 代价/钩：内侧的规则落地（说话被吃半句）；芙兰摸到半个字的位置（ch51 的另一半）。

**场 3**｜时间地点：同日，正午｜锅壁内侧·灶眼
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：窄道通到一处凹进去的灶眼，壁上渗着一层薄糖浆，地上有一圈被火烤白的石台。琉玥用银匙刮了一点渗液，想尝，被芙兰按住——她自己尝不出，琉玥的舌头是队里最后一条。芙兰让琉玥尝，问三样，琉玥答「咸先、甜后、挂勺」。芙兰据此判断灶眼朝下的风是从锅底上来的。
- 对话要点：
  1. 芙兰：「这凹进去的，是灶眼。」
  2. 老塞：「底下的人在这儿熬。」
  3. 琉玥：「壁上渗的，是糖。」
  4. 芙兰：「别尝——」（想起自己尝不出）「你尝。咸先还是甜先。」
  5. 琉玥：「咸先。甜在很后面。挂勺。」
- 代价/钩：补偿四件第一次派上用场（问＋记）；琉玥成了队里的「舌头」。

**场 4**｜时间地点：同日，午后｜锅壁内侧·灶眼上方
- 在场人：芙兰、柯林、薇尔、琉玥、老塞
- 核心行动：灶眼上方的糖壳顶忽然往下塌。柯林把薇尔和琉玥往两边推，自己的左臂被塌下来的糖壳咬住。琉玥用银匙柄撬糖壳，撬不开；薇尔用封条封住糖壳边缘，糖壳停了一下，芙兰用盐霜撒在咬口上，糖壳松了。柯林把手抽出来，肘以下垂着，手指还能动三根。
- 对话要点：
  1. 柯林：「薇尔，后面——」
  2. 琉玥：「手！把手给我！」
  3. 柯林：「拉不出来……」
  4. 薇尔：「三指。还能动三指。」
  5. 柯林：「我没事。我那天肚子疼。」（他自己先笑了一下）
- 代价/钩：柯林左臂废（肘以下垂着，只能动三指）；盐霜试出「糖壳怕盐」——后面逃生用。

**场 5**｜时间地点：同日，黄昏｜锅壁内侧·岔口
- 在场人：芙兰、琉玥、薇尔、老塞、柯林
- 核心行动：两条岔道，一条往上、一条往下，都黑。芙兰让琉玥尝两边壁上的渗液，琉玥说上面的淡、下面的厚；芙兰又看糖晶长的方向（朝下）、算熬声的间隔（下面更密），判断往下是锅底、往上是回口。她说走上面，先出去，明天午前要赶灯船的期限。

  2. 琉玥：「上面的淡。下面的厚。」
  3. 芙兰：「糖晶朝下长。熬声下面更密。走上面。」
  4. 薇尔：「我记：上淡下厚，走上面。」
  5. 老塞：「你算得对。」
- 代价/钩：补偿四件（问＋看＋算）第二次派上用场；他们选了回口，不知道回口已经塌了一半。

**场 6**｜时间地点：同日，夜｜锅壁内侧·回口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：回口的糖壳顶在往下坠，缝比进来时窄了一半。老塞把撑杆横过来顶住，数「九十二」。就在这时，整个腔体往下一沉——像锅底翻了个身。熬声停了一拍，然后从脚底下传来一声更沉的「咕」。所有人都听见了。
- 对话要点：
  1. 老塞：「别出声。它在翻。」
  2. 芙兰：「翻？」
  3. 老塞：「锅底翻了个身。」
  4. 琉玥（低声）：「它在看我们。」
  5. 老塞：「它不看。它熬。」
- 代价/钩：钩子落地——底下那个东西「翻了个身」（实动）；回口的缝被压窄，撑杆开始受力（ch57 断杆的起点）。

**本章代价**：柯林左臂废（肘以下垂着、只能动三指）；全队伤；盐霜用掉一瓶；回口被压窄，撑杆开始受力；船期剩一天。
**钩型**：实动——锅底翻了个身，回口的缝窄了一半。
**章末落点**：那声「咕」落下之后，缝顶的糖壳「咔」地裂了一道，老塞把撑杆又顶紧了半寸。
**阶／格露头**：无。

**场 6**｜时间地点：同日，清晨｜锅壁口·灶边

- 核心行动：芙兰坐在灶边，把断杆上的刻痕一道一道数过去：九十一、九十二、九十三。她向薇尔要了炭笔，在断杆最下面刻上「塞德里克」四个字，刻得很浅。刻完她把断杆包进摊布，抱在怀里。
- 对话要点：
  1. 芙兰（数）：「九十一，九十二，九十三。」
  2. 琉玥：「走吧。」
  3. 芙兰：「我把他名字刻在杆上。」
  4. 薇尔：「我册上也写了。」
  5. 芙兰：「他忘了我叫什么。我记得他叫什么。够了。」
- 代价/钩：断杆成为遗物；芙兰把「记名字」接了过来（卷六的动机）。

**本章代价**：老塞死（塞德里克，名字交给芙兰）；撑杆断在第九十三回；芙兰得到半截断杆；埃利亚斯答应替老塞看火。
**钩型**：静收——「名字给你。你别忘。」
**章末落点**：她把断杆抱进怀里，像抱一根撑不了人的杆；灶膛的火被埃利亚斯压小，锅底「咕」了一声，没有人再说话。

## ch58 归

**日**：第 25–27 日｜**本章事件**：回城与下行的岔口；克劳斯最后报价；城门口告示上芙兰的名字被写成「已死」；柯林回城；芙兰、琉玥、薇尔继续往下。

**场 1**｜时间地点：第 25 日，上午｜盐场·码头
- 在场人：芙兰、琉玥、薇尔、柯林、布伦丹
- 核心行动：布伦丹的数：五个人下去，四个人上来；他把船资的账当众报了一遍（盐、船、人手），报完在自己的手背上记了一道。芙兰把断杆放在船板上，先不上去。薇尔在册上写「四个」。
- 对话要点：
  1. 布伦丹：「后天到了。你们五个人上去，四个人。」
  2. 芙兰：「四个。」
  3. 薇尔：「账上写四个。」
  4. 柯林：「我回城。」
  5. 布伦丹：「小舌头——」（他改口）「芙兰。船明天卯时开。」
- 代价/钩：五人变四人（老塞的死落进账里）；布伦丹改口叫她名字（她还有名字，只是不在册上）。

**场 2**｜时间地点：同日，中午｜码头·棚下
- 在场人：芙兰、薇尔、琉玥、柯林、索恩
- 核心行动：索恩从灯船下来，把一张抄件放在棚下的木箱上：城门口贴的告示，行会与协会联署，上面写着「一百零七号，已死」。索恩说完就走，走前看了一眼芙兰手里的断杆。薇尔把告示上的字逐条读出来，读到「已死」停住。
- 对话要点：
  1. 索恩：「城门口贴的。抄件。」
  2. 芙兰（看）：「一百零七号。已死。」
  3. 薇尔：「册上也是这么写的。」
  4. 芙兰：「那就省得他们再划一次。」
  5. 琉玥：「你回不去了。」
- 代价/钩：回城的路被一张纸堵死（名字已死）；「回城」从选项变成对照。

**场 3**｜时间地点：同日，下午｜码头·棚下
- 在场人：芙兰、克劳斯、索恩、薇尔
- 核心行动：克劳斯亲自下船，把一张收归文书和一张通行证并排放在木箱上：签了，名字改成「失踪」，船票他出，琉玥复职、柯林通缉撤；不签，明天午前灯船靠岸，盐场按「藏匿资产」办。芙兰把通行证推回去，只问了一句「签了，罐子归谁」。
- 对话要点：
  1. 克劳斯：「签这张。名字改成『失踪』。船票我出。」
  2. 芙兰：「签了，罐子归你。」
  3. 克劳斯：「按册子来。」
  4. 芙兰：「我的名字不在你册子上。」
  5. 克劳斯：「册子可以再写一行。」
- 代价/钩：回城的诱惑开到最大（通行证＋复职＋撤通缉）；她拒绝，等于替三个人选了往下。

**场 4**｜时间地点：同日，傍晚｜码头·船边
- 在场人：芙兰、柯林、薇尔、琉玥
- 核心行动：柯林把腰间的布袋解下来，倒出历年考试的号码纸，一张一张数，数到「一百零五」那张停住；他把那张留给芙兰，其余收回布袋。他说自己回城，街上得有人记得老塞；他抬起左手，说手废了，考不成了，但号码纸还能留着。薇尔在他那页册上写下名字。
- 对话要点：
  1. 柯林：「我回去。街上得有人记得他。」
  2. 芙兰：「你的手。」
  3. 柯林：「明年，我再来。」（他说完看了看自己的左手）
  4. 薇尔：「我把名字写你册上。」
  5. 柯林：「别写错号。一百零五。」
- 代价/钩：柯林回城（带走老塞的名字与自己的号码纸）；队伍开始分开；芙兰手里多一张「一百零五」的号码纸。

**场 5**｜时间地点：同日，夜｜盐场·盐池边
- 在场人：芙兰、琉玥、薇尔、布伦丹
- 核心行动：琉玥把自己的银匙、扁银盒、黄铜小秤在盐池边排开，说停职回去也是等查，手也拿不稳匙；她留下。薇尔把册子摊开，说自己的名字已经不在册上，回去也没那一行；她也留下。布伦丹把船契收起来，说船他卖给盐工了，明天卯时柯林一个人上船。
- 对话要点：
  1. 琉玥：「我停职。回去也是等查。」
  2. 芙兰：「你的手——」
  3. 琉玥：「我替你尝。」
  4. 薇尔：「我记。」
  5. 布伦丹：「船给柯林。你们三个，往哪走？」
  6. 芙兰：「往下。」
- 代价/钩：队伍定下「三下、一上」；琉玥的舌头、薇尔的册子成了下行的两条腿。

**场 6**｜时间地点：第 27 日，卯时｜锅壁口·缝口
- 在场人：芙兰、琉玥、薇尔、埃利亚斯、柯林（远处船上）
- 核心行动：芙兰把告示抄件折好，压在断杆下面；她把罐子背回怀里，罐里已经没有糖，只有两块陶片和一小撮盐霜。埃利亚斯把灶膛的火压小，说灶上的火他替老塞看着。芙兰对琉玥说「下次下去，我们带够糖」，琉玥说「带够」，薇尔在册上记「欠：糖」。缝里的风把告示的纸角吹起来，露出「已死」两个字。
- 对话要点：
  1. 芙兰：「下次下去，我们带够糖。」
  2. 琉玥：「带够。」
  3. 薇尔（记）：「欠：糖。第 27 日。」
  4. 埃利亚斯：「锅不等人。」
  5. 芙兰：「我也不等它。」
- 代价/钩：她选择继续往下（不回城）；回城的对照留在告示上（名字「已死」）；老塞的名字、断杆、册子、琉玥的舌头带上路。

**本章代价**：回城的路（名字「已死」，册上无她）；柯林回城、队伍分成「三下、一上」；老塞的断杆成为遗物；罐子里不再有糖（半颗已尝，只剩陶片与盐霜）。
**钩型**：信息——城门口告示上，她的名字被写成「已死」。
**章末落点**：她最后看了一眼那张告示，纸角被缝里的风吹起来，露出「已死」两个字；她把断杆往肩上挪了挪，先走进缝里。
**阶／格露头**：无。

### 硬规则校验

1. **每章 6–7 场**：53／54／55 各 7 场，56／57／58 各 6 场，共 39 场。
2. **五字段**：时间地点／在场人／核心行动／对话要点（3–5 句、标说话人）／代价·钩，逐场齐。
3. **钩型**：反转（53）→信息（54）→悬念（55）→实动（56）→静收（57）→信息（58），无连三。
4. **每章代价**：舌头契（53）、清零（54）、名字无册（55）、柯林左臂（56）、老塞死（57）、回城路断（58）——全部具体可数。
5. **不露脸、不点名**：底下那个东西只有「熬声」「翻身」「咕」「影子先动」；全段没有它的脸、形状、名字；第七位只以「空位」出现，不写全名。
6. **不新增人物／地名**：出场人物全部已有（埃利亚斯、克劳斯、布伦丹、尤金、索恩均在册）；地点全部来自 `docs/places.md`（盐场、锅壁口、锅壁内侧）与既有船（灯船）。未写新地名。
7. **ch54 补偿**：问（琉玥替尝三样）、记（薇尔「芙兰的味」页）、看（断面／光／丝）、算（火候／时辰／熬声间隔）；ch56 场 3／场 5、ch58 场 6 各用一次。
8. **ch57 老塞**：不写血、不写惨状，只写撑杆断、糖壳合、名字交接；撑杆「九十一、九十二、九十三」与 ch42／ch45 对账。
