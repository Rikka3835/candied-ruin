# 1D 糖泡 · 第 1 批规格表（高清球资产 + 静止对照）

> 用途：把"塑料感"一次解决。**只做静止球**，不碰爆炸、不碰底色、不碰折射、不加发光、不改时序。
> 规矩：本表 9 条全部可量化，交付时逐条打勾；任一条不达标即为未完成。

## 一、范围（这一批做什么）

- 只重做**点击反馈用的糖球本体**（以及它的 8 帧状态图），不改其余任何视觉与逻辑。
- 输出：1 张高清基准资产（程序化生成，可重生成）+ 8 帧状态 + 三档 DPR 缓存策略。

## 二、9 条验收（逐条量化）

### 1. 尺寸与定位
- 直径 `D = clamp(round(min(W,H) * 0.07), 56, 72)`；1440×900 → **63px**；390×844 → **59px**。
- 定位只保证**泡体**在屏内（`D/2 + 2` 边距），十字允许出屏。
- 验收：截图量像素，误差 ≤ 2px。

### 2. 外轮廓
- 不再是完美圆：半径做低频抖动，**幅度 ≤ ±3%**；共 **3 个变体**，每颗泡按 seed 取一个 + 随机旋转。
- 外缘 **1px 深色收口**（`rgba(90,42,6,.85)`），**禁止任何外发光/光环**。
- 验收：3× 放大图看边缘是否"手绘感"而非几何圆弧；变体数量 == 3。

### 3. 色带（硬边，不用平滑渐变）
- **6 段**，色值固定：
  `#8A4A0E → #B9661A → #E08A2A → #FFB347 → #FFD276 → #FFE9B8`
- 色带圆心**向右上偏移** `(-0.10R, -0.12R)`（偏心＝有光照，同心＝靶心＝塑料）。
- 验收：取像素直方图，确认存在 6 个主色簇；圆心偏移可从最亮带位置量出。

### 4. 高光与细节
- 高光＝**实心硬边椭圆** `0.20R × 0.15R`，旋转 `-0.5rad`，**不允许模糊光斑**。
- 星点 **2 颗**，尺寸 1–2px，硬边，不发光。
- 底部：**透光月牙**（`rgba(255,226,160,.42)`，0.83R）＋ **底缘暗弧**（`rgba(110,52,10,.5)`，0.97R）。
- 验收：3× 放大图逐项可见。

### 5. 8 帧状态
| 状态 | 帧数 | 时长 | 说明 |
|---|---|---|---|
| 待爆呼吸 | 4 | 1600ms 循环 | 轻微膨胀 98%→103%，无位移 |
| 预警（引信最后 1s） | 3 | 1000ms 循环 | 膨胀到 106% + 边缘泛红 `rgba(255,90,30,.28)` + 2px 抖动 |
| 爆前闪白 | 1 | 80ms | 整体提亮 +18%，不透明度不变 |
- 验收：逐帧截图，帧数 == 8。

### 6. 播放与帧率
- 在 `requestAnimationFrame` 内按时间取帧号切换，**不用 setInterval / CSS steps**。
- 两种模式：`?smooth=0` 纯 12fps 精灵（原版顿感）／`?smooth=1` 帧间插值（60/120fps 平滑）。
- 验收：面板读 rAF 间隔，6 球同时在场时 **平均 ≥ 58fps**，最长单帧 ≤ 20ms。

### 7. 几何不变式（本批不得改动）
- 臂宽 = **1.0D**；每向伸出 = **5.0D**；缩回 = **2.5D**；缩回无伤害；引信 **5000ms**。
- 验收：`still(100)` 与 `still(380)` 各量一次跨度，`815±10px` / `406±10px`（D=81 时），比例 10.0D / 5.0D。

### 8. 性能约束
- 每颗泡每帧 **≤ 1 次 `drawImage`**（贴图预烘焙，按 `(D, DPR)` 缓存命中）。
- 内存：8 帧 × 3 档 DPR × 3 变体 ≤ 72 张小画布，总量 ≤ 4MB。
- 验收：Performance 面板手动计时 + 缓存命中日志。

### 9. 交付物（截图 + 表）
1. **并排对照图**：QQ堂 原版精灵（56px，放大 3×）｜我们的球（63px，放大 3×）｜我们的球（实际 1×）
2. **8 帧状态图条**（每帧标注 ms）
3. **参数表**：色值、色带半径占比、圆心偏移、高光尺寸、帧序与毫秒、D 计算式
4. 一段 2 秒录屏或 GIF（呼吸 + 预警各一次，证明帧率）

## 三、明确不做（出现即为超范围）
- 不加任何发光/光环/bloom
- 不改爆炸（糖条）与连锁
- 不改底色（保持深焦糖棕 `#2a1a10`）
- 不做折射/动态高光（那是第 3、4 批）
- 不做泡质分级配色（永远单一琥珀色）
