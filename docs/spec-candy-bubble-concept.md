# 糖泡 · 构成概念稿 v1（先定形态，再写代码）

> 一句话：**糖泡不是糖球，是「一泡糖」——透明糖膜包着高浓度糖浆，四道糖筋把它绷成球。**
> 这是世界内的东西，不是游戏道具：书里可以出现「糖泡」这个词，但不出现任何游戏化术语。

## 一、六层构成（对应 concept-bubble.png 的标注）

| # | 层 | 是什么 | 视觉职责 |
|---|---|---|---|
| ① | 糖膜（外壳） | 熬到透明的糖壳，薄、有厚度、有黏性 | 提供球体积、边缘光、折射界面 |
| ② | 泡质（内层糖浆） | 高浓度糖浆，密度大，缓慢对流 | 提供"里面在动"的重量感 |
| ③ | 膜-浆界面亮环 | 折射率差形成的一圈内壁亮线 | 让"有壳"这件事一眼看得出 |
| ④ | 悬浮气泡 / 糖晶 | 熬制时裹进去的小气泡与未化糖晶 | 提供近看细节，提供"糖"的身份 |
| ⑤ | 四道糖筋 | 拉糖时留在球内的四道糖丝，沿十字方向 | **十字爆炸的世界内解释** |
| ⑥ | 底部加厚 | 糖浆下沉，膜底更厚更暗 | 重量感、接触阴影的依据 |

## 二、动（三种状态，不含数值 UI）

1. **待破**：膜随内部压力轻微起伏（变形，不是整体缩放）；内部糖浆缓慢对流；高光随膜移动。
2. **将破**（最后一段）：对流加速、膜上出现细糖纹、光从纹里透出来。
3. **破**：沿四道糖筋绷裂 → 十字；糖膜碎片飞散；糖浆沿四方向涌出后回落；地面留糖渍。

## 三、与现实「糖泡」的关系（借构造，不借现实感）

你发的那份资料是**油炸面食「糖泡」**和一款**糖泡洗洁精**。可借的是"**糖壳包糖心**"的构造与"配方/工艺"的叙事口吻；不可借的是油炸面食的焦褐、油光、面体质感——那会让它变成"食物"，不是"武器化物质"。

## 四、正文/网站都要做的「去游戏化」替换

| 现在（游戏味） | 改成（世界内） |
|---|---|
| 泡质 G / S 级 | 成色：新蜜 / 老蜜 / 稠蜜 / 凝蜜 |
| 技能树 | 糖艺谱系（师承、流派） |
| 配方 | 方子 / 手记 |
| 冷却、伤害数值 | 现象描述（"三息之内不能再凝"） |
| 关卡、BOSS | 第几层、深处之物 |
| 攻击手段 | 手段 / 手法（书里不用"技能""武器"这类词） |

## 五、三个待定（必须你拍板才能开工做材质）

1. **膜厚**：薄透（像吹糖，折射明显、破口薄脆）／厚壳（像糖壳，更硬、破口是块状）？
2. **泡质颜色**：单一琥珀（现状）／按熬制程度分层（新蜜浅蜜、稠蜜深焦糖）？
3. **十字来历**：四道糖筋（我提的）／膜沿经纬四向绷裂／四瓣糖壳？

确认后进入材质：WebGL2 解析球面（真折射 + 透射 + 动态高光 + 内部对流），手机降级 Canvas2D 静态球。
