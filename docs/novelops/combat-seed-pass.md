# 战斗铺垫（combat-seed-pass）

> 目的：ch24 第一场正式战斗之前，读者必须先见过三样东西的苗头——**猫的敏捷、鼻子先于眼睛、尝是有代价的**。
> 依据：`docs/combat-bible.md`（体系）、`docs/world-v2-draft.md`（成长）、用户 2026-10-30 指令「ABC 都要」。

## 一、铁律（违反即退回）

1. **只加，不改。** 不动剧情、台词、章末钩、账目数字、人物生死。
2. **每处 3–5 行，最多 5 行。** 全章汉字增幅 ≤ 250。
3. **不解释系统。** 不许出现「阶」「格」「蜜术」「技能」这些词（唯一例外：ch11 允许出现一次「格」，因为尝旧蜜掉格）。
4. **不写明喻。** 不许写「她像猫一样」；只能写动作：蹲、跳、落地没声、先侧头再转身。
5. **必须贴在现有物件上**：现成的墙、门轴、石阶、锅、糖纸、风。
6. **不新增人物、地名、道具**（不许突然出现一条新巷子）。
7. **指标门**：mean 11–16、叙述短段 ≤72%、他说/她说 ≤2/千字、破折号 ≤3/章；跨章重复 0。
