# 故事圣经（摘要）

> 正源：创世与神系见 `docs/world-genesis.md`；人物全卡见 `docs/characters.md`；写法见 `docs/story-bible.md`。

## 一句话宇宙观
世界不是被创造的，是被熬出来的；整块（神躯）被分食后只剩半颗，另外半颗一直在别人嘴里。

## 关键术语
- 泡质 / 糖型 / 糖晶：力量与材料的三个词，正文只用「糖型招式」「配方底牌」。
- 六味：初甜（蜜主）、回甘（守忆）、尾苦（记账人）、涩口（持界）、水味（被刮去）、铁腥（赤蜜）。
- 七个位子：六神 + 第七位（被刮干净，不留一字）。
- 旧蜜 / 帕芙利亚 / 蜜契行会 / 浮泡商盟 / 圣蜜都 / 瓦拉罗 / 帕尔。
- 试糖人：靠舌头替人鉴糖换钱的底层行当；规矩「试糖人贪一口，味觉就废」。
- 尝女：圣蜜都每代一名，只尝合格，不说话。

## 主要人物（一句）
- 芙兰：猫族 16 岁试糖人，要攒 34 枚买橱窗第三格的「整块」。
- 玛尔塔：糖铺老板娘，卖糖的不吃糖，赊账册记着芙兰 3 枚半。
- 哈根：西边糖农，「明年我还来」，留了一包样糖。
- 皮普：12 岁小贩，缺颗门牙，街上消息比谁都快。
- 老塞：老水手（真身守密人），摸得出甜但尝不出。
- 琉玥：鉴评所见习品糖师，把味道翻译成人话。
- 薇尔：商队账务学徒，只凭规则说话。
- 奥托·蓝姆：商盟旧蜜分部管事，味觉只剩三成。
- 伊莎贝尔：圣蜜都密使，烧糖时念祷词。
