# 本书规则（红线）

## 硬红线
1. 第一人称（芙兰），只写她能感知到的。
2. 正文禁止：等级、面板、技能树、数值、系统提示。力量只靠他人反应、身体代价、物件变化交代。
3. 禁「不是……而是……」句式（上一稿被抓过四次）。
4. 具体数字不要堆：一章最多留 3 个数字，且要跟钱/差多少有关。

## 信息节奏（读者投诉过）
5. 一章最多 2 个新名字 + 1 个新概念（人名预算）。超了就挪到下一章。
6. 设定只用动作呈现：不写「我是试糖人」，写她尝完吐掉、嚼干面包。
7. 名字晚给：先叫「糖铺老板娘」，认脸了再补名字。
8. 开头 300 字内不出现新专名。
9. 段落节奏：短段（≤12 字）≥45%，长段（≥60 字）≤10%。

## 关系（轻百合五条，已批准）
10. 全书 0 次告白；只写 3 次「差一点」；两种温度不争；每章浓度 ≤10%；只有结局「帮我尝尝」明写。

## 章法
11. 一章 2,800 字（±200），章末必须有钩子，硬软交替，不连三硬。
12. 每章 2–3 个专有名词上限，旧词优先于新词。

## 人物锁
- 芙兰（定稿 2026-10-28，以角色设定卡为准）：聪明、张扬、任性、野猫式自由，有点坏心眼但不坏，对喜欢的东西执着到不讲理。**不许写成自卑、讨好、卑微算账型**；她的自嘲是有底气的自嘲，被戳穿是顶回来而不是低头。
