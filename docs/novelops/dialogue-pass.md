# 对话松绑规范（dialogue-pass v1）

用户 2026-10-30 原话：「对话是不是太文艺了……现在小说是不是还是太文绉绉了」「该冷的时候要冷 比如有危机感的时候 日常就是要轻松愉快 该有就有 比如俩人吵架 第三个人 扶额 表情 神态 吐槽 什么的 这才像人写的 轻小说」「不要再强调糖是苦的 是不是苦的 读者自己会通过剧情判定」。

## 0. 这次只做什么
改**对话与对话周围的反应**。不改：情节、信息、结局、章末钩、账目数字、物件、时间线。
不许增删人物。不许换掉台词里的事实（报了多少钱、糖几层、谁欠谁）。

## 1. 三条病根（照这个改）
1. **每个人都把话说完整**：一问一答、主谓宾齐全、句句有用。真人说话会断、会重复、会答非所问、会把话说一半被抢走。
2. **现场没有第三个人**：吵架就俩人吵，旁边的人像不存在。轻小说的人味在旁观者的反应上——扶额、叹气、翻眼、往后退半步、装没听见、插一句风凉话。
3. **每段都在推进剧情**：没有废话、没有跑题、没有走神。人说话会突然拐到别的事上，再拐回来。

## 2. 允许的四把刀（每章至少用三种）
- **抢话**：被对方打断，用破折号收尾，下一行换人说。一章 1–3 次，别滥用。
  - 例：「我不是那个意思——」「那你是什么意思。」
- **答非所问 / 说半句**：问价答天气，问名字答「你猜」。
- **第三个人**：有的人在场，句子就不是两个人对打了。用动作不用形容词。
  - 例：老太太把瓜子换到另一只手，说「我押两枚。」
  - 例：玛尔塔抬起那四根手指，在眉心按了一下，像在按一颗钉子。
  - **提醒**：这是例子，不是配额。有的场景两句话、没人插嘴，反而更活（比如验货、报数）。别为了"有第三个人"硬塞。
- **废话**：一句与主线无关但属于这个人的话（抱怨天气、算账、惦记晚饭）。一章 2–4 句，不能多。

## 3. 冷热切换（按场景定，不按章定）
- **日常/市井/吃饭/走路**：可以松、可以贱、可以跑题。对话段 35–45%。
- **危机/验货/对峙/死人**：短句、少废话、不吐槽；反应只写手、呼吸、脚步。对话段 25–35%。
- 同一章里允许切换，但切换要有触发物（门开、蜡断、有人报数）。

## 4. 声线卡（改台词时对表）
- **芙兰**：短句，答话常省主语；被问私事会先反问；紧张时说话更快更碎；**不说漂亮话**。
- **玛尔塔**：慢，喜欢把话说到一半让人接；算钱时数字咬得重；对小辈用「你」不用名。
- **哈根**：一句话说两遍（第二遍更轻）；「明年我还来」；不会说谢。
- **老塞**：答非所问，爱用海上的比方；从不解释自己。
- **琉玥**：敬语，但敬语里带刺；问题都是为记录服务的。
- **薇尔**：口吃在数字上（越要紧越结巴）；说「我记一下」。
- **莉娜**：公事公办，句尾常带「按规定」。
- **奥托**：话少，先给结论再给理由。
- **伊莎贝尔**：教会的白，不说脏字，用「不洁」「该烧的」。
- **皮普**：数数、拖长音「～」可用（全书 ≤30 处，他是主要来源）。
- **雅各布**：每次只多给半句，从不解释来历。

## 5. 禁写清单
- 主题解释句：「糖是苦的」「甜是假的」「这世上的甜都要还」这类总结句，一句都不许有。苦不苦让读者自己尝。
- 总结式感慨段（以「我知道」「我明白」开头讲道理的段落）。
- 每个角色都懂事的对话（所有人都听懂暗示、都接得住）。
- 连续 3 行以上纯「」问答、中间没有任何动作/神态。

## 6. 指标门（用 scripts/tmp_struct_scan.py 复测）
- dial：日常章 35–45%，危机章 25–35%；全书均值 33–40%
- 叙述短段 ≤70%
- 「他说/她说」≤2/千字（三人以上同场才允许用，且尽量用动作替代）
- 破折号 ≤5/章（台词内被打断不计）

**注意：上面只是死指标（防止改坏），不是"鲜活"的标准。** 用户原话：「我都说了 举例子的 不要一定按照我这个要求 我只是想要鲜活的感觉」。→ 不许把「每章至少 1 处第三人反应」当 KPI 去凑数；凑出来的反应 beats 比没有更假。

## 6.5 鲜活怎么判断（每次改完拿这五条自查，别数数）
1. **这个人此刻有身体吗**：手在干什么、嘴上说着什么、脸上是什么表情，三者不必一致（嘴上客气、手上攥紧）。
2. **有没有一句"没用的话"**：不是每句都得推动剧情；一句废话能证明这人不在为你服务。
3. **有没有人不在状态**：走神、饿了、惦记别的、被旁边的动静分心——现场的真人总会有一两个不在戏里。
4. **有没有人失礼或失手**：说错称呼、抢话没抢成、笑错地方、话说重了又往回找补。
5. **读出声顺不顺**：念一遍，别扭的地方就是该动的地方（这一条比任何指标都准）。

## 7. 交付格式
每章一句：改了几处对话、dial 前后、有没有动到事实；另用一句话说这章的「活」落在哪（不要报 beat 数量）。
