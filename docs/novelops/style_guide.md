# Style Guide

> 本书正文的唯一文风准则。写任何一章之前读一遍；写完用文末「四条可机械核对」自检。
> 依据：22 章实测基线（改前 56,018 汉 / 均句 9.1 / 短段 85%）与《地错》对照（均句 17.8 / 短段 47–58%）。

## Narrative distance

- 第一人称「我」＝芙兰，**限知**。只写她的舌头、鼻子、手指、耳朵能收到的东西；不许写别人的心理活动。
- 感官顺序固定：**味觉 → 触觉/温度 → 听觉 → 视觉**。看见什么之前，先尝到什么。
- 允许她猜，但必须写成猜：「他应该在笑。」不写成事实：「他在笑。」
- 旁人内心一律靠**外部证据**转译：手停住、杯沿偏了半寸、话说半句咽回去。作者不下判断。

## Sentence energy

- **均句 12–14 汉字**（下限 11，上限 16）。句子短＝字幕，句子长＝小说。
- 一个叙述段＝1–3 句，其中至少一句 20 汉字以上；连续两句都在 8 字以内，必须并进上一句或下一句。
- **锤句配额**：每章保留 15–25 句 5–8 字的短句，用在拍子上（落刀、揭盖、报数、关门）。锤句不许连排三句以上。
- 并句用逗号，不用「然后」「于是」「接着」。并句后只保留一个主语。
- 每段第一句不许以「我」开头超过三段中一段。

## Diction

- 名词优先于形容词，数字优先于程度词。**能报数就报数**：三枚半、八枚、十二颗、第四层、一百零七。
- 味觉词表（只用这些，不发明）：甜、苦、涩、酸、咸、铁、烟、灰、蜡、旧衣服、回甘、焦、糊、凉。
- 糖的写法：先说出它在舌上的位置（舌根/舌侧/上颚），再说层次，最后说它像什么旧东西。
- 禁抽象情绪词：难过、愤怒、害怕、委屈、震惊、复杂。改成身体反应或动作。
- 禁 AI 定型句：「不是……而是……」「声音不高，却……」「不容置疑」「仿佛在诉说」「空气中弥漫着」。

## Dialogue density

- 对话段占全章 **30–34%**（按段计数），叙述段 66–70%。
- 「他说／她说」每千字 ≤2 次。能用动作带出说话人就用动作。
- 交叉对白**必须分行**：一人一句一行，禁止并成一句（并句会丢掉「谁在答谁」）。
- 单人连续说话超过 60 字，中间必须插一个动作或对方的一句短反应。
- 每个人说话的句子长度要不同：芙兰 6–12 字，薇尔 18–30 字，玛尔塔 4–8 字，琉玥 8–14 字。

## Taboo moves

- 章首不许时间状语开场（「第X天」「第二天早上」）。从动作、声音、气味切进去。
- 章末不许用同型短陈述收（「我回家了。」「天亮了。」）。钩型按实动/悬念/信息/反转/任务/静收轮换，同类不许连用三章。
- 破折号 ≤3 个/章；省略号 ≤2 个/章。
- 一段里同义动作只写一次（关门、塞回塞子、回头看一眼），发现重复就删后一处。
- 不许出现游戏词：副本、任务、系统、面板、等级、经验。
- 景物清单连续超过 3 句而没有动作，删到 2 句。
- 不许「她很难过」式总结句；付账必须具体可数（铜印、回甘、一个人的自由、一份记录）。

## 四条可机械核对（写完必跑）

1. 均句 ≥11 且 ≤16；短段占比 ≤70%。
2. 连续 ≥3 句、每句 ≤12 汉字的「短句串」出现次数 ≤2/章。
3. 「他说／她说」≤2 次/千字；交叉对白全部独立成行。
4. 破折号 ≤3、无跨章重复段落（脚本查重为 0）。

## 主角欲求（每场都要能被看见）

芙兰的欲求句：**她要有人肯为她那条舌头作保——把她当人，不当一条会尝的舌头。**

三个可直接写的观察点（每场至少出现一个，不许写成内心独白）：

1. 先报数、再报味道——她要先证明自己值这个价。
2. 别人只问味道、不问她的名字时，她少说一句。
3. 收钱数两遍；人情不数。

> 卷三每场自检一句：这一场里，她想要的这件东西，被人给了还是被人拿走了？答不上来的场，删。

## 文书卡（告示 / 封条 / 信件 / 账页）
正文里出现的「纸」，不要写成叙述转述，用独立块，由构建器渲染成卡片：

```
:::notice 行会告示
四一七批号
暂缓入册
待核
:::
```

- 四种 kind：`notice`（公告）、`strip`（封条，窄、居中）、`letter`（信件）、`ledger`（账页/味记）。
- 第一行 `:::kind 标签`：标签会渲染成小字标题，可省略。
- 块内每行一句，不写标点以外的修饰；卡片前后各留一个空行。
- 用途：行会告示、教会封条、商盟账页、信件、味记页、批号单。凡是「角色在读一张纸」，都用它，不要用引号复述。

## 芙兰的皮（人物一致性·2026-10-30 用户定）

她是野猫，不是懂事的孩子。每章至少留一处「皮」，手法只许五种：

1. **赖账/占便宜**：顺一颗糖渣、少报半枚、拿话堵人（「三枚半。」「你昨天说四枚。」「昨天是昨天。」）
2. **逗人**：故意把价钱说反、学人说话、明知故问。
3. **话说一半**：吊着对方，等对方自己接。
4. **身体先出卖她**：耳朵转过去、尾巴卷起来、指尖在桌上敲——她自己不承认。
5. **被戳穿时理直气壮顶回去**：不脸红，耳朵先动一下，然后反将一军。

禁区：不许写成吵闹、撒娇、卖萌讨好；她逗人是带刺的，不是可爱的。每章最多两处，别铺满。

## 阶与格：怎么明写但不弹面板

- 全书只有两个词：**阶**（灰/白/蜜/焦/金箔，术式的深浅）与**格**（舌头能记住的味数）。
- 露出规则：**每章最多两处**，且必须由人说出口，或她自己在心里数；**禁止叙述报数**（不许「她的格是 3」）。
- 现有底数：芙兰入行 4 格，ch11 尝旧蜜后剩 2 格；琉玥 8 格；赫伯 1 格；薇尔与玛尔塔不尝（0）；老塞 0 格（味觉已废）。
- 升阶必须有人付账：芙兰 ch26 灰→白（掉一格）；琉玥 ch31 白→蜜（右手留疤）；薇尔 ch30 灰→白（名字被抹）。

## 巨神：卷三一次都不许露脸

- 卷三（ch23–34）里**不许出现巨神的名字、面目、声音的正面描写**。
- 只许三种痕迹：被涂黑的壁画、下面传来的熬糖声、别人说到一半就改口的话。
- 越往后越要让读者觉得「那东西大到没法打」——靠规模和代价写，不靠形容词。
