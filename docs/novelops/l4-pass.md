# L4 活人感终审作业（第五轮，2026-10-31）

## 你要做什么

逐章读 `content/chapters/` 里分配给你的章节，**只做 L4「活人感」层面的微调**，让场面像有人在现场，而不是一台问答机器。改完交简报。

## L4 八问（每章读的时候依次问）

1. **有没有一句失礼的话？** 人在不耐烦、害怕、心虚时会说难听话。全员礼貌＝AI。
2. **有没有一句废话？** 天气、价钱、谁家孩子、昨晚没睡好。不推进剧情，但让世界有别的活人。
3. **有没有一个人不在状态？** 有人在擦柜台、有人在数钱、有人根本没在听。不是所有人都盯着主角说话。
4. **身体有没有出卖自己？** 说「没事」但手在抖；说「不饿」但咽了一下。**只写身体，不写注解**。
5. **作者有没有想让你感动？** 凡是「她没有哭，但我知道她很难过」「这一刻我明白了」这类替读者定位情绪的句子，删。
6. **对话是不是太对仗？** 一问一答都严丝合缝、每句都答在点上、每人说话一样长 → 抢话、答非所问、说一半被打断、重复自己。
7. **场景里有没有脏东西？** 地上有水、桌角有缺口、衣服上有糖渍、苍蝇、灰。干净得像样板间＝假。
8. **读出声会不会绊舌？** 连续三个「的」、两个同音字挨着、一句话里四个「了」→ 改顺。

## 允许的改动（只这四类）

- 在**连续 4 段以上纯对话**中间，插一句 15–40 字的叙述（动作、环境、身体）。
- 把一句**过度整齐**的台词改成抢话/半句/答非所问（**只能改叙述与语气词，引号里的信息量不许变**）。
- 删掉**替读者总结情绪/意义**的句子。
- 补一处**脏东西或环境声**（一句话以内）。

## 禁止

- 不改剧情、不改人名、不改数字、不改章末最后 3 段、不改任何钩子。
- 不新增人物、不新增地名、不新增设定。
- 不加「凑数反应」（「他愣了一下」「众人哗然」「有人笑了一声」这类没有信息量的群体反应）。
- 每章改动 ≤4 处；全章字数变化 ≤±3%。
- 不跑 build / git / 不碰 docs 与 public。
