## ch29 第一带·锅沿

**场 1**｜时间地点：入井后第一个时辰｜城西废井底·锅沿口石坎
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：井盖在头顶合上，光断。热从脚底漫上来，像站在刚撤火的灶台边。老塞把罩着铜网的鱼油灯挂在撑杆上，先迈下石坎，用杆尾敲地：笃、笃、噗——噗的那块不落杆。芙兰把罐子换到胸前，用摊布角打结；薇尔数人，数到五停住；柯林伸手扶壁，立刻缩回来。
- 对话要点：
  1. 老塞：「脚跟着我。踩亮的地方——亮了，就是壳薄。」
  2. 薇尔：「规矩是——火折子不许点。灯行，明火不行。」
  3. 老塞：「糖粉见明火就炸。这底下，火比刀快。」
  4. 柯林：「这点热，我扛得住。」
  5. 芙兰（闻）：「甜在下面。很近，贴着地。」
- 本章代价推进：队伍知道自己带着什么下来（罐、灯、伤药、绳）；第一笔账先记在「谁走最前」上——老塞的脚。

**场 2**｜时间地点：入井后第二个时辰｜锅沿糖壳坡
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：坡面是半透明的糖壳，底下暗红，像灶膛。芙兰忽然抬手，全队停住。她低头闻，又侧耳；糖壳下有东西擦过去，很轻，像湿布拖过锅底。她抛一粒糖晶屑，屑子落地，坡面某处陷下去又弹回来。她指左边绕。薇尔数步子；柯林把短棍换到右手。
- 对话要点：
  1. 芙兰：「站住。有东西在闻我们。」
  2. 老塞：「闻风的。这一带的舌头。」
  3. 琉玥：「先别说话。」（她蹲下听壳）
  4. 芙兰：「它吃血，不吃糖。别弄破皮。」
  5. 薇尔：「绕过去，十七步。」
- 本章代价推进：绕路十七步——路变长，水囊第一次开；芙兰把这次「闻风」记在心里（她只剩两格，闻一次少一次准头）。

**场 3**｜时间地点：入井后第三个时辰｜旧钩子糖壳桥
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：一道糖壳桥横在热沟上，宽只够一人。沟底糖浆咕嘟翻泡，泡破时溅起甜腥的热气。老塞先过，撑杆在桥面点三下：笃、笃、噗——第三下不实。柯林第二个，走到中间，脚下一软，芙兰一把扣住他后领；罐子从她怀里滑了半寸，她用下巴顶回去。琉玥第三个，薇尔最后。
- 对话要点：
  1. 老塞：「钩子。以前有人在这儿搭过桥。」
  2. 琉玥：「糖在流。桥是自己长的。」
  3. 薇尔：「三个人过去，桥短一寸。」
  4. 柯林：「我先过。我轻。」
  5. 芙兰：「罐子给我。你手空着。」
- 本章代价推进：桥短一寸——退路先于敌人被削掉。他们把「只能往前」这件事踩实了。

**场 4**｜时间地点：入井后第四个时辰｜桥头窄台
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、猎食的小兽（一只）
- 核心行动：柯林殿后。黑暗里扑出一只四足的东西，没有眼睛，嘴裂到耳根，身上沾着干糖壳。柯林挥短棍，棍打在它肩上；它一口咬住他左小臂，拖。芙兰贴舌一退——尝到扑面的血甜，反手把糖晶屑撒进它鼻孔；它甩头。琉玥的银匙从侧面敲在它耳后；老塞的撑杆横着叉住它脖子，把它顶下热沟。沟底一阵翻腾。
- 对话要点：
  1. 柯林：「我没事——」
  2. 芙兰：「你流血了。」
  3. 老塞：「血止住。这一层闻血。」
  4. 琉玥：「它在等血。它不吃糖，等的是血里的糖。」
  5. 芙兰（贴舌后）：「它嘴里有糖。血里有糖。」
- 本章代价推进：柯林左臂见血——队伍第一次流血，账本第一笔落地。

**场 5**｜时间地点：入井后第四个时辰末｜桥头窄台
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：薇尔撕下自己袖口给他扎臂，扎得很紧，柯林咬着牙没出声。血滴在糖壳上，没有摊开，被吸了进去；壳下暗红亮了一下，像灶膛里被吹了一口气。芙兰蹲下，用铜勺刮起一点带血的糖壳放进嘴里——甜里带铁，糖是温的，在舌头上动了一下。老塞看着那点亮光，说带上。
- 对话要点：
  1. 薇尔：「它在喝。」
  2. 柯林：「我拖累你们了。」
  3. 芙兰：「你挡了那一下。账记我头上。」
  4. 老塞：「活的糖。下一层认这个。」
  5. 芙兰：「它认得血。」
- 本章代价推进：血被糖壳喝掉；一块带血的活糖进袋——下一带的门票先付了，用柯林的血。

**场 6**｜时间地点：入井后第五个时辰｜糖壳尽头·向下裂口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：糖壳断出一道向下的裂口，口沿结着白霜。芙兰把带血的糖片贴上去，糖片化开一点，往裂口里侧淌，像指路。她回头，井口的光早没了。底下传来一声很低的「咕」——像一大锅糖翻了个泡，又像什么东西咽了一口。她先伸脚。
- 对话要点：
  1. 老塞：「下。」
  2. 琉玥：「下面在动。」
  3. 芙兰：「它尝到了。」
  4. 薇尔：「罐子抱紧。」
  5. 芙兰（低声，给自己）：「它尝到了。它记住这个味了。」
- 本章代价推进：退路（桥短一寸）＋柯林的血已经落下去；带血的活糖糖片化掉一半，剩下一半是下一层的引子。

**本章代价**：柯林左臂见血（队伍第一次流血）；一块带血的活糖（下一带的门票）；糖壳桥短一寸（退路）。
**钩型**：危机——血滴在糖壳上，下面的东西动了（钩子原话：「它尝到了。」）。
**章末落点**：裂口底下的黑里，那声「咕」又响了一次，比刚才近。
**阶／格露头**：芙兰心里数「闻风用掉一次」——不报数（0 处明数）。

## ch30 第二带·糖霜阶

**场 1**｜时间地点：入井后第五个时辰末｜裂口下·糖霜阶口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：裂口下是一道极长的石阶，阶面覆着白霜，脚一踩就黏，抬脚时「啵」一声。老塞把剩下的活糖片按在阶面上，糖片化开，往右下角淌。柯林左臂吊着，走得慢；琉玥把他的短棍接过去背在自己背上。薇尔开口数阶，只报数，不报别的。
- 对话要点：
  1. 老塞：「糖会指路。跟着它化的边。」
  2. 琉玥：「霜是甜的。别舔。」
  3. 薇尔：「第一阶。第二阶。」（她数得很平）
  4. 柯林：「我能走。」
  5. 芙兰：「你走我后面。手别扶壁。」
- 本章代价推进：活糖片化掉一半——门票在消耗；柯林每走一步都在计息（血已经流了一次）。

**场 2**｜时间地点：入井后第六个时辰｜糖霜阶中段
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：阶侧的霜底下有刻痕。薇尔用指甲刮开一片霜：底下是「号」，浅口、斜刀，一个挨一个，像账页。芙兰摸自己铜印的背面——同一种刻法。刻痕旁边本该有名字的地方，被磨平了。老塞看了一眼，没停脚。
- 对话要点：
  1. 薇尔：「这些是号。」
  2. 芙兰：「跟铜印背面一个刻法。浅口，斜的。」
  3. 老塞：「行会来过。过阶留名，老规矩。」
  4. 琉玥：「名字呢。」
  5. 老塞：「名字在下面。」
- 本章代价推进：他们先知道「要交名字」，才走到名槽——代价先被看见，才落下来。

**场 3**｜时间地点：入井后第六个时辰末｜阶底·白蜡封着的凹槽
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：阶底有一道凹槽，槽口封着一圈老白蜡，蜡边有指甲印。芙兰刮一点蜡放舌尖：甜，甜里有哈喇的尾。薇尔蹲下看蜡色，翻册子，指尖停在一行；老塞用三根手指捻蜡屑，捻得很慢。三个人各说一段，谁也没把话说完。
- 对话要点：
  1. 芙兰：「甜在蜡里。」
  2. 薇尔：「蜡九成，糖一成。账上写过这一笔。」
  3. 老塞：「蜡放久了会哈。糖盖那个味。」
  4. 薇尔：「掺进去的糖，批号是四一七。」
  5. 琉玥：「他们烧糖。自己的蜡里掺糖。」
  6. 芙兰：「所以他们烧的不是脏。是账。」
- 本章代价推进：真相落袋：白蜡掺糖，为盖变质，掺的是教会自己判脏的四一七。三个人各记一段，谁也说不全——这是后面没人信的根。

**场 4**｜时间地点：入井后第七个时辰｜阶底·名槽
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：名槽边的阶面上刻着一行旧规矩：下行者留名。老塞说他的名早押在册上，不欠这一道。琉玥刚要伸手，被薇尔拦住。薇尔从芙兰手里拿回自己的铜徽章，用徽章边角在阶上刻「薇尔」——只有名，没有姓。最后一笔落下，霜从笔画上漫过去，字被喝进去。薇尔的脸白了一瞬，手还在刻。柯林叫她「账房那个」，叫完自己愣住。
- 对话要点：
  1. 薇尔：「规矩是——下行留名。我的名字，册上早就没了。」
  2. 芙兰：「我来。」
  3. 薇尔：「你的名字还要用。」
  4. 老塞：「它收一半。」
  5. 柯林：「账房那个——」
  6. 芙兰：「她叫薇尔。」
- 本章代价推进：薇尔的名字刻上阶、被喝掉一半——本章主账落地。柯林那一句「账房那个」是名字开始滑的第一声。

**场 5**｜时间地点：入井后第七个时辰末｜阶底
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：霜从薇尔刻字的手指爬到手腕，绕成一圈白，像戴了只霜镯子。老塞看了一眼，说「它借了你。白。」薇尔把袖子拉下来盖住那圈白，说册子还在她怀里。芙兰想替她擦，擦不掉，指腹上沾了一层凉。琉玥问她手冷不冷；她说冷，又说走。
- 对话要点：
  1. 老塞：「它借了你。白。」
  2. 薇尔：「白就白。册子还在我怀里。」
  3. 芙兰：「擦不掉？」
  4. 薇尔：「擦不掉。」
  5. 琉玥：「手冷不冷。」
  6. 薇尔：「冷。走。」
- 本章代价推进：霜镯子＝甜渊的借据（灰→白，代价已付）；她开始把袖子拉长——名字少了，人还在。

**场 6**｜时间地点：入井后第八个时辰｜阶底平台·回望
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：他们下到第二层的平台，芙兰回头。阶上「薇尔」两个字只剩半边，另半边像被谁用拇指抹过，切口上的霜是新的。老塞说收了一半，剩下一半是她还剩下的。薇尔没有回头，只说走。芙兰把那半边的样子记在眼里。
- 对话要点：
  1. 芙兰：「你的名字——」
  2. 薇尔：「还在。」
  3. 老塞：「收了一半。剩下一半，是你还剩下的。」
  4. 芙兰：「另外一半呢。」
  5. 薇尔：「走。」
- 本章代价推进：半名字——账没结清，留到卷四；甜渊只收走「册上那一半」，街上还认得她。

**本章代价**：薇尔的名字（册上再没有她；阶上刻名被收走一半）；活糖片化尽（门票用完）；薇尔的铜徽章（刻名时磨掉一个角）。
**钩型**：静收——阶上刻的名字被人擦掉一半（钩子原话：「收了一半。」）。
**章末落点**：她回头时，那两个字只剩半边；切口上的霜是新的，像刚被人用拇指按过。
**阶／格露头**：老塞口里的「白」（薇尔的借）——1 处；不报数。

## ch31 第三带·血管廊

**场 1**｜时间地点：入井后第八个时辰末｜血管廊口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：廊壁是暗红的，软，会随呼吸鼓起来；脚一踩，壁就往里让。血味先到——铁锈、咸、温热。琉玥走了三步就停住，鼻翼动了两下，脸色变了：糖味没了。芙兰舔了一下空气里的湿，尝到血里有糖，很薄。老塞把灯举低，说这一层不靠鼻子。
- 对话要点：
  1. 琉玥：「闻不到。糖味没了。」
  2. 芙兰：「我尝得到。血里有糖。」
  3. 老塞：「血味盖糖味。这一层，鼻子是聋的。」
  4. 薇尔：「跟着她的舌头走。」
  5. 琉玥（低声）：「我这一行，最怕有一天尝不出来。」
- 本章代价推进：琉玥的鼻子废在这一层——全队的路改由芙兰的舌头付。她的罩门第一次被地利用。

**场 2**｜时间地点：入井后第九个时辰｜血管廊中段
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、巴伦、三个商盟打手
- 核心行动：前面钩子响，铁链拖在糖壁上。巴伦从廊侧岔口出来，左手铁钩，钩尖挂着干糖壳；身后三个打手，手里短棍。巴伦从怀里抖出一张商盟悬赏单，单子上「一百零七」被红笔圈着。薇尔上前半步讲条款；巴伦把单子拍在廊壁上。
- 对话要点：
  1. 巴伦：「罐子。人。」
  2. 芙兰：「谁的单。」
  3. 巴伦：「主事的单。你的号，一百零七。」
  4. 薇尔：「商盟没有在甜渊里拿人的条款。」
  5. 巴伦：「钩子不认字。」
- 本章代价推进：悬赏单亮出 107——铜印第一次变成别人的价；退路被堵。

**场 3**｜时间地点：入井后第九个时辰末｜血管廊中段
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、巴伦、三个打手
- 核心行动：巴伦的钩子甩出，钩住柯林吊着的左臂，一收，把人拖倒。柯林短棍脱手。芙兰撒糖晶屑，屑子在空中被钩风带偏；薇尔扑上去，把一张行会封条按在一个打手的脚背上，那人脚钉在地上，摔了个跟头；她的封条用掉一张。琉玥举银匙，血味冲得她判断错位，匙子落空。
- 对话要点：
  1. 巴伦：「先废一条胳膊。」
  2. 柯林：「别管我——」
  3. 薇尔：「商盟打手，无令入渊——」
  4. 巴伦：「闭嘴。」
  5. 芙兰：「柯林，低头。」
- 本章代价推进：柯林伤上加伤；薇尔用掉一张封条（她的账上多一笔）；琉玥第一次失准。

**场 4**｜时间地点：入井后第十个时辰｜血管廊中段
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、巴伦、打手
- 核心行动：芙兰贴舌一退，尝血定位，闭着眼报：左边三步，钩子要回，他脚下有糖。琉玥闭上眼，不再靠鼻子，靠温度、声音、手感：拉丝成索，缠住柯林腰把人拽回来；熬糖成刃，用廊壁渗出的糖割钩索；封蜡定形，把两个打手的脚封进糖里。她抓住滚烫的糖索换手，掌心「滋」一声，白泡鼓起来。她没有松。
- 对话要点：
  1. 芙兰：「左边三步。钩子要回。」
  2. 琉玥：「知道了。」
  3. 芙兰：「再左半步。他脚下有糖。」
  4. 琉玥：「封住了。」
  5. 巴伦：「这丫头——」
  6. 芙兰：「你的钩子，收不回了。」
- 本章代价推进：琉玥右手起泡留疤（拿匙的手）；她借这层的糖升了半阶——账记在她手上。

**场 5**｜时间地点：入井后第十个时辰末｜血管廊中段
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、巴伦、打手
- 核心行动：芙兰贴身上前，小刀划开巴伦前臂，血溅在廊壁上。廊壁猛地一缩，像被烫着，随即往血的方向挤；两个打手的脚被糖壁咬住，惨叫。巴伦去拔钩子，钩子卡在糖里拔不动，他弃钩，拖着伤臂往岔口退。血顺着壁沟往下流，廊壁一鼓一鼓地喝。
- 对话要点：
  1. 巴伦：「钩子——」
  2. 芙兰：「留下吧。」
  3. 老塞：「这层喝血。他再不走，就走不了了。」
  4. 琉玥：「我的手——」
  5. 芙兰：「别碰。先包上。」
- 本章代价推进：巴伦的血喂了廊，钩留下——他的名（钩子）丢在这儿；芙兰的小刀卷了刃。

**场 6**｜时间地点：入井后第十一个时辰｜血管廊尽头
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：廊尽头立着一扇门，门框是糖晶长的，门缝里吹出冷风，风里有被拉长的声音。门上有一圈白蜡封，封口被人开过又按回去，蜡边留着指印。芙兰摸蜡：软、滑，不是行会的涩蜡。薇尔翻开册子比对，摇头：行会的图上没有这扇门。老塞把耳朵贴在门上。
- 对话要点：
  1. 琉玥：「门后有回声。」
  2. 老塞：「那不是回声。是有人在里面说话。」
  3. 芙兰：「谁。」
  4. 老塞：「你听。」
  5. 薇尔：「行会的图上，没有这扇门。」
- 本章代价推进：门被找到——下一带的入口是别人封过的；白蜡封口被他们弄开一半，痕迹留下。

**场 7**｜时间地点：入井后第十一个时辰末｜血管廊尽头·门前
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：芙兰用铜勺柄挑开蜡封。门里传出一声很轻的、被拉长的「啊——」，像有人隔着很多层布在念什么。柯林把短棍捡回来，握在左手里，右手扶着墙。老塞把灯交给薇尔，自己先推门；门轴没有响。
- 对话要点：
  1. 芙兰：「门没锁。」
  2. 老塞：「锁在里头。」
  3. 薇尔：「进？」
  4. 老塞：「进。灯举高。」
  5. 柯林（低声）：「我走最后。」
- 本章代价推进：门开了——他们跨进第四带之前先欠下「这扇门不该有」这笔账；白蜡封被破坏。

**本章代价**：琉玥右手留疤（拿匙的手；蜜色渗进疤里＝白→蜜的借据）；柯林伤上加伤；薇尔一张行会封条；巴伦的钩留在糖里（他丢了名）；芙兰的小刀卷刃。
**钩型**：实动——廊尽头有一扇不该有的门（钩子原话：「那不是回声。是有人在里面说话。」）。
**章末落点**：门开了一条缝，冷风把灯焰压弯；门里的黑比外面深。
**阶／格露头**：琉玥「白→蜜」由老塞一句「借了半阶」带出——1 处；她不报数。

## ch32 第四带·喉道

**场 1**｜时间地点：入井后第十二个时辰｜喉道口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：门后是窄道，壁上有软骨似的环，一环扣一环；说话有回声，回声比原话长。柯林喊了一声「薇——」，回声回来只剩「……尔」，他的嗓子立刻哑了，像被掐了一下。薇尔一把捂住他的嘴，掏出炭笔在纸上写：别说话。全队改成写字、手势、唇语。
- 对话要点：
  1. 柯林：「薇——」
  2. （回声）「……尔。」
  3. 薇尔（纸上）：「说话会被吃掉。」
  4. 老塞（低声）：「一个字，一口。」
  5. 柯林（哑）：「我没事。」
- 本章代价推进：柯林的声音被吃掉一半——全队从此闭嘴；消息只能写、只能看。

**场 2**｜时间地点：入井后第十二个时辰末｜喉道中段·号码壁
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：壁上刻满号，一个挨一个，全是行会的浅口斜刀。每个号旁边都有一个被刮平的名字，刮得最干净的那一行，号是「四一七」。芙兰摸那个号，指腹停住；薇尔在纸上记；老塞不看壁，看路。
- 对话要点：
  1. 薇尔（写）：「号是行会的。」
  2. 老塞（低声）：「名字是它的。」
  3. 芙兰：「那我们是第几个。」
  4. 老塞：「别数。」
  5. 芙兰（摸到四一七）：「这个号，我见过。」
- 本章代价推进：号码壁：他们看见过道的历史——号留下，名字刮掉；芙兰知道自己要交的是什么。

**场 3**｜时间地点：入井后第十三个时辰｜喉道中段·印槽
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：壁上凹进去一个印形的槽，槽口封着蜡——涩，掺松香，指甲一刮起白痕。芙兰用指甲刮了一下，想起封条上那股涩。槽的大小正好是一只铜印。薇尔在纸上写行会条款；写完把纸举给芙兰看。琉玥伸手按住芙兰解绳的手。
- 对话要点：
  1. 薇尔（写）：「在册试糖人过层，以牌为质。一牌引一队。」
  2. 芙兰：「行会的规矩，在这儿管用？」
  3. 老塞：「它认牌，不认人。」
  4. 琉玥（按住她的手）：「想清楚。」
  5. 芙兰：「想清楚了。」
- 本章代价推进：涩蜡＝行会的程序在这里管用；牌能引一队——铜印即将离身。

**场 4**｜时间地点：入井后第十三个时辰末｜印槽前
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：芙兰解下颈上的绳，把铜印按进槽里。槽口的涩蜡软下去，像被体温化开。她必须说一个号给喉道——她说「一百零七」。回声把这三个字拖长、吃掉；印沉进壁里，槽口合拢，蜡面平回去。她脖子上只剩一根空绳，绳结还是热的。
- 对话要点：
  1. 芙兰：「一百零七。」
  2. （回声）「一百……零……」
  3. 薇尔（写）：「它收了。」
  4. 老塞：「走。」
  5. 芙兰（摸空绳）：「印是押的。人是走的。」
- 本章代价推进：铜印 107 沉进壁里——身份的一半押出去；行会册上她还是活人（没销号签字），程序救了她，也把她变成「册上的人、渊里的号」。

**场 5**｜时间地点：入井后第十四个时辰｜喉道后段
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：他们往前走。身后回声忽然叫「芙兰」——不是柯林的哑嗓子，也不是她自己的声音，是从壁里出来的，很近。薇尔在纸上写：别回头。芙兰不答，脚步没停。回声又叫了一声，近了一点，尾音拖着甜。琉玥伸手握住她的手腕，握得很紧。
- 对话要点：
  1. （回声）「芙兰。」
  2. 薇尔（纸上）：「别回头。」
  3. 琉玥（唇语）：「走。」
  4. 老塞（低声）：「它记住你了。」
  5. 芙兰（心里）：「不答。」
- 本章代价推进：回声叫她的名字——名字进了喉道，账转到她头上；她第一次在甜渊里「有名字」。

**场 6**｜时间地点：入井后第十四个时辰末｜喉道尽头
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：窄道忽然开阔，风从前面来，暖、甜、带酸，像掀开一锅放凉的糖浆。回声被留在身后。柯林试着出声，嗓子回来一点，第一句话是「你的印」。芙兰摸脖子上的空绳，说押出去了。薇尔在纸上写：册上还有你。
- 对话要点：
  1. 柯林（哑）：「你的印……」
  2. 芙兰：「押出去了。」
  3. 薇尔（写）：「册上还有你。」
  4. 芙兰：「那就够了。」
  5. 老塞：「前面就是胃囊。」
- 本章代价推进：全队过道；芙兰的印留在喉道；她只剩册上的名字和一根空绳。

**场 7**｜时间地点：入井后第十五个时辰｜喉道出口·胃囊风口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：芙兰第一个跨过喉道口。罐子撞在壁沿上，发出一声闷响，像里面有东西翻了个身。胃囊的壁上有什么动了一下，很远，像一面墙在呼吸。老塞停了一步，说「到了」。
- 对话要点：
  1. 老塞：「到了。」
  2. 芙兰：「这层是什么。」
  3. 老塞：「它以前叫——」（停住）
  4. 芙兰：「叫什么。」
  5. 老塞：「先走路。」
- 本章代价推进：跨进第五带；罐子第一次在下面响——它认得这层。

**本章代价**：铜印 107（沉进喉道壁里）；芙兰的名字进了回声；柯林的嗓子（哑了半程）；全队从此不能出声。
**钩型**：危机——回声里有人叫她的名字（钩子原话：「它记住你了。」）。
**章末落点**：她跨过去时，身后那声「芙兰」停了，像被谁捂住了嘴。
**阶／格露头**：无（本章不报阶、不报格）。

## ch33 第五带·胃囊

**场 1**｜时间地点：入井后第十五个时辰末｜胃囊·入口糖脊
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：胃囊大得看不到边，壁是粉白的，挂着糖霜和黏液，地中央一条糖脊能走人，两边是浅糖浆。罐子在她怀里慢慢变暖。柯林开始发烧，嘴唇干裂；琉玥把水囊递给他，他摇头。老塞走在最前，忽然在一处壁刻前停下。
- 对话要点：
  1. 琉玥：「这层的糖是活的。」
  2. 老塞：「这层是它吃饭的地方。」
  3. 薇尔：「别靠壁。」
  4. 芙兰：「柯林在烧。」
  5. 老塞：「走快些。」
- 本章代价推进：柯林发烧、水见底——第五带的账先记在身体上。

**场 2**｜时间地点：入井后第十六个时辰｜胃囊·旧壁刻前
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：壁上有一道旧刻，三道并排的短痕，像用三根手指划的。老塞用自己缺了两指的手去比，正好合上。他说上一次下来，是跟「第七位」一起。芙兰问第七位是谁；老塞说，是册子上的那个空位。薇尔翻册子：七个位子，第七个是空的。芙兰再问他人呢，老塞不答，反问她「你觉得呢」。
- 对话要点：
  1. 老塞：「上一次下来，我跟第七位一起。」
  2. 芙兰：「第七位是谁。」
  3. 老塞：「册子上的那个空位。」
  4. 薇尔：「册上七个位子，第七个是空的。」
  5. 芙兰：「他人呢。」
  6. 老塞：「你觉得呢。」
- 本章代价推进：老塞的过去开账：「第七位」这个名字第一次落地；他知道的不肯全说。

**场 3**｜时间地点：入井后第十六个时辰末｜胃囊·壁画前
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、守层者
- 核心行动：囊腔深处，一个半糖的人形跪坐在一幅壁画前，手里一把刮刀，一下，一下，刮壁上的画。它的背壳是糖，手臂是糖，脸是平的——没有五官，只有被磨平的浅坑。它不攻击。老塞站住，叫它，它抬头，用刮糖一样的声音说话。
- 对话要点：
  1. 老塞：「……还在。」
  2. 守层者：「你带人来了。」
  3. 老塞：「我带人来了。」
  4. 守层者：「名字。」
  5. 老塞：「你还记得你的名字吗。」
  6. 守层者：「……」（刮刀停在壁上）
- 本章代价推进：守层者拦路——不是打，是要一个名字；老塞的记名被逼到手上。

**场 4**｜时间地点：入井后第十七个时辰｜胃囊·壁画前
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、守层者
- 核心行动：老塞把撑杆插进糖脊，三根手指并拢，叫出一个名字——声音出口就被囊壁吸走，听不完整。守层者的刮刀「嗒」一声落在地上，人形定住，像蜡凝了。老塞的肩塌下去，扶住撑杆，张了张嘴，说记不得跟自己下来的人叫什么了。他让芙兰别扶，说三天。
- 对话要点：
  1. 老塞（叫名，声音被吸走）
  2. 守层者：「……」（定住）
  3. 老塞：「我记不得……跟我下来的人，叫什么了。」
  4. 芙兰：「老塞。」
  5. 老塞：「别扶我。三天。」
- 本章代价推进：老塞用掉一次记名（一生三次，剩两次），忘掉「第七位」的名字——他的账最贵，用记忆付。

**场 5**｜时间地点：入井后第十七个时辰末｜胃囊·壁画前
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、守层者（定住）
- 核心行动：守层者定住后，壁画全露出来：七个位子，六张脸清清楚楚，第七个被刮得只剩一圈白，边上是新新旧旧的刮痕。芙兰看那圈白，觉得眼熟；薇尔翻开册子，翻到夹着净火节文书的那一页——文书角上的火漆印，一圈弧，底下收成一个尖。她把两样东西并在一起看。
- 对话要点：
  1. 薇尔：「这个印——教会的文书上，盖的就是这个。」
  2. 芙兰：「他们把这张脸刮了，又拿它当印。」
  3. 琉玥：「谁刮的。」
  4. 老塞：「它自己。」
  5. 芙兰：「第七位，就是这张脸？」
  6. 老塞：「……走。」
- 本章代价推进：真相：教会的印＝被刮掉的第七张脸；老塞用记忆换来的，是这个答案的一半。

**场 6**｜时间地点：入井后第十八个时辰｜胃囊·壁画前
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、守层者
- 核心行动：守层者的手指动了，刮刀被它重新捡起来；定住的时限到了。老塞说它醒了就记不得我们，走。柯林烧得走不稳，芙兰让他走自己旁边。他们退出去，守层者的刮刀「嗒」一声，又刮在白圈上。
- 对话要点：

  2. 薇尔：「下面还有路。」
  3. 老塞：「有。今天不走。」
  4. 柯林（烧）：「我能走。」
  5. 芙兰：「你走我旁边。」
- 本章代价推进：他们退——今天不往下走；老塞三天不能动手；柯林的烧加重。

**本章代价**：老塞一次记名（一生三次，剩两次）；老塞忘掉「第七位」的名字；柯林发烧加重；水囊见底。

## ch34 无底

**场 1**｜时间地点：入井后第十八个时辰末｜胃囊尽头·向下洞口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：囊壁收成一个向下的洞，洞口结着糖壳，风从下往上吹，冷，带着甜焦味。老塞半边身子靠在撑杆上，三天没到，手不能动；柯林额头发烫；琉玥右手包着布，用左手扶人；薇尔蹲下清点：水囊、干面包、绳。
- 对话要点：
  1. 薇尔：「水剩半囊。面包两块。绳子还剩一截。」
  2. 芙兰：「够回去。」
  3. 琉玥：「老塞不能动手。」
  4. 芙兰：「我知道。」
  5. 老塞：「我没死。走。」
- 本章代价推进：补给清点：半囊水、两块面包、一截绳——可数；全队伤。

**场 2**｜时间地点：入井后第十九个时辰｜无底洞口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：薇尔往洞里丢一块糖，侧耳听；没有落底声。柯林从腰间布带里抽出一张号码纸，丢下去；纸也没有声。芙兰数到三十，停了。老塞说别数了，没有底。风从洞里上来，把灯焰吹得往一边倒。
- 对话要点：
  1. 薇尔（丢糖）：「没有底声。」
  2. 柯林（丢号码纸）：「连纸都没有声。」
  3. 芙兰（数到三十）：「三十。」
  4. 老塞：「别数了。没有底。」
  5. 琉玥：「下面是空的？」
  6. 老塞：「不是空。是深。」
- 本章代价推进：一块糖、一张号码纸扔进洞；「没有底」这件事落地——不是深度，是尺度。

**场 3**｜时间地点：入井后第十九个时辰末｜无底洞口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：洞下面传来声音：搅锅、刮底、糖浆翻沸、勺子碰锅沿；有节奏，一阵一阵，像有人守着火。琉玥听出中间那个停顿——三指挂勺，等糖挂到第三指才起锅。薇尔跟着数拍子。芙兰尝风里的味：甜、焦、旧衣服。罐子在她怀里发烫。
- 对话要点：
  1. 琉玥：「有人在下头熬糖。」
  2. 薇尔：「一直在熬。拍子没乱。」
  3. 芙兰：「甜，焦，旧衣服。」
  4. 老塞：「这个就叫——底。」
  5. 琉玥：「它在等谁。」
  6. 老塞：「等它熬完。」
- 本章代价推进：熬糖声＝下面的东西在「做饭」；罐子发烫——它在应声；全队听见，知道下面不是能打的东西。

**场 4**｜时间地点：入井后第二十个时辰｜无底洞口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：琉玥说都到这儿了；柯林说他能走；薇尔算账：下去容易，上来没有绳。芙兰看洞，又看老塞的手——三天没到，他动不了。她决定撤，说不是怕，是还没学会怎么下去。老塞没反对，只说下去容易，上来难。
- 对话要点：
  1. 琉玥：「都到这儿了。」
  2. 芙兰：「到这儿，才知道下面不是打的。」
  3. 老塞：「下去容易，上来难。」
  4. 芙兰：「那就先学会怎么上来。」
  5. 柯林：「我听你的。」
  6. 薇尔：「我记下这一笔。没下去。」
- 本章代价推进：决定撤回：把「下去」留成债；补给不再消耗，但全队的伤都带回去。

**场 5**｜时间地点：入井后第二十个时辰末｜胃囊·回程
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：他们沿糖脊往回走。薇尔走在最后，用指甲把来时做的记号一道道抹掉。芙兰问她为什么；她说下面的人不用知道我们来过。柯林走不动，琉玥用左手扶他；老塞靠撑杆，一步一步。罐子还在芙兰怀里。
- 对话要点：
  1. 薇尔：「记号我抹了。」
  2. 芙兰：「为什么。」
  3. 薇尔：「下面的人不用知道我们来过。」
  4. 芙兰：「回去的路呢。」
  5. 薇尔：「我记着。」
  6. 老塞（低声）：「海的那边，也这样。」
- 本章代价推进：来路记号被抹（保护，也让回程只剩薇尔的记忆）；全队伤着往回走。

**场 6**｜时间地点：入井后第二十一个时辰｜无底洞口·回望
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：芙兰最后一个离开洞口。她回头看了一眼：洞里黑得没有反光，熬糖声还在，一勺，一勺。她把罐子往怀里按紧，对琉玥说下次下去，我们带够糖。琉玥说带够。她说完，洞里的熬糖声停了一拍，像有人听见了。
- 对话要点：
  1. 芙兰：「下次下去，我们带够糖。」
  2. 琉玥：「带够。」
  3. 老塞：「海的那边，也这样。」
  4. 薇尔（低声）：「先上去。」
- 本章代价推进：承诺落地——续篇的账先记下；罐子还在她怀里，底下的东西已经听见她的声音。

**本章代价**：全队伤（柯林发烧、琉玥右手、老塞三天、芙兰空绳）；补给空（半囊水、两块面包、一截绳）；来路记号被抹；罐子还在她怀里。
**钩型**：收束（续篇）——「下次下去，我们带够糖。」
**章末落点**：她说完，洞里的熬糖声停了一拍，像有人听见了；然后，又一勺，一勺，接着熬。
**阶／格露头**：无。

1. **不露脸、不点名**：六章通读，那个东西只以「它／下面的东西／底」出现，无一处描写、无一处名字；痕迹逐章升级：29 血被喝→31 廊壁收缩→32 回声叫名→33 壁画被刮→34 洞底熬糖。越往后越像「大到没法打」：31 是环境反应，32 是它知道她的名字，33 是它把一张脸刮掉，34 是它在下面「做饭」。
