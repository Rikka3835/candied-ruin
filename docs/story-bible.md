# 《糖渍旧蜜》写作圣经（编辑用）

> 世界观正源（创世/六神/圣蜜都/年表/伏笔表）见 `docs/world-genesis.md`；本文件只管写法与卷章。

## 1. 定死的参数
- 人称：第一人称（芙兰）
- 章长：2800 字（±200），一屏约 800 字，一章 3–4 屏
- 语气：7:3 偏轻小说；短句 15–25 字；吐槽只在“期待与现实的落差”处
- 红线：正文不出现等级 / 面板 / 技能树 / 数值；力量靠他人反应、身体代价、物件变化交代
- 名词投放：每章最多引入 2–3 个专有名词

## 2. 四卷 42 章
卷一《糖罐里的猫》8 章 / 卷二《甜味走私者》12 章 / 卷三《巨神之躯》12 章 / 卷四《旧蜜与半颗糖》10 章
（逐章事件与钩子见 docs 目录外的对话记录；本文件只存原则，避免两份不一致）

### 四卷章末钩子（各不相同）
1. 卷一：信息钩 —— 糖袋徽记＝橱窗第三格那颗糖上的旧印
2. 卷二：选择钩 —— 救薇尔，但要放走粗糖
3. 卷三：危机钩 —— 守密人：「你们三个里，有一个不该下去」
4. 卷四：情绪钩 —— 「帮我尝尝」

## 3. 关系与留白（轻百合纪律，用户已批准）
1. 全书 0 次告白，不出现“喜欢你”三个字
2. 只写 3 次「差一点」：擦嘴、掰开的半块糖、雪地里握住手腕——都不点破
3. 两种温度不争：琉玥＝懂她味道的人；薇尔＝替她挡住世界的人
4. 任意一章百合浓度 ≤10%（约 280 字）；它是盐，不是主菜
5. 只有结局那句「帮我尝尝」明写亲密，前面全部留白
