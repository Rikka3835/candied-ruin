# 糖泡 · 1D 材质与动作规格表（T1 / WebGL2）

> 状态：**待用户审**。本页经用户逐条对过：膜=气球皮（薄透、无碎片）、泡里装糖浆、放置期顶部压陷弹回、炸后干净消失。
> 原则：**不加任何小道具**（冲击环/糖雾/震动一律不做），冲击感由本体材质与动作承担。

---

## 0. 不做什么

- 不做像素精灵、不做 8 帧位图循环（该路线已作废）。
- 不加冲击环、不加糖雾/糖尘、不加屏幕震动。
- 不做颜色分级（单一琥珀）。
- 不做糖壳碎片（膜“啪”一下消失，无片）。

---

## 1. 形态与材质

| 项 | 规格 |
|---|---|
| 结构 | 一层薄透糖膜 + 内部高浓度糖浆（**没有硬壳**） |
| 颜色 | 单一琥珀族：本体 `#FFB347`，亮部 `#FFE0A0`，暗部 `#8A4A0E`，膜边高光 `#FFF6DC` |
| 膜 | 薄透：边缘可见一圈亮边（宽度 ≈ 0.03D），能透出后面一点点（折射强度 0.15–0.25） |
| 内部 | 糖浆缓慢对流（速度 ≤ 0.3D/秒），近看有两三颗小气泡/糖晶 |
| 尺寸 | 桌面 **48–56px**（视口短边 ≥900 取 56，<700 取 48）；手机 **44–48px** |
| 静止观感 | 不能有外发光；不许有描边塑料感；立体感靠明暗三层 + 边缘亮边 |

## 2. 放置期动作（5.0 秒，共 5 次，匀速）

每一次 **1.0s**：压下去 0.55s，弹回带阻尼 0.45s。五次幅度相同，**不加速**。

单次变形（相对静止态）：

| 部位 | 变化 |
|---|---|
| 整体高度 | **−8%** |
| 整体宽度 | **+4%**（体积守恒） |
| 顶部额外下凹 | **再 −3%**（顶部落差合计约 11%） |
| 底部 | 接触面变宽，下沿压扁（贴地感） |
| 弹回 | 过冲 **+2%** → 微回 **−0.5%** → 归位，阻尼约 0.2s 收住 |

必须同时满足（否则像贴纸）：
1. 压陷处**内壁可见**（凹进去的那一圈要能看见膜的背面）；
2. 高光**跟着位移**（压下去时高光下沉，弹回时滑上来）；
3. 轮廓整体参与变形（不是局部一块皮在动）。

## 3. 爆炸时间表（从第 5 次压弹结束算起，t=0）

| 阶段 | 时间 | 内容 | 伤害 |
|---|---|---|---|
| 炸膜 | 0–40ms | 沿十字四向先撕开四道口，随后**膜与泡体当场消失**（不留本体、不留碎片、不拖泥带水） | — |
| 涌出 | 40–120ms | 糖浆从四道口涌成四根糖柱，冲到 **5.3D**（过冲） | — |
| 落位 | 120–150ms | 从 5.3D 落回 **5.0D**，一次到位，不来回 | — |
| 顶住 | 150–300ms | 停在 **5.0D**；**平头**；**不抖动**；亮度最高；颜色与糖泡本体一致 | **有效** |
| 收势 | 300–420ms | 整根退回 **2.5D**，匀速、不弹跳、不造伤 | **无效** |
| 收掉 | 420–480ms | 从 2.5D 收干净；**480ms 后与该糖泡相关的一切消失** | — |
| 痕迹 | 480ms 后 | **不留糖渍**（一点不留，符合“炸得干净”） | — |

> 修正记录（按用户 2026-10-27 口述）：**没有“回抽 2.5 再顶回 5.0”那一段**——出去 5.0（有过冲）→ 顶住 → 收回 2.5 → 收干净，就结束。

几何：臂宽 **1.0D**；**端头为平头（直角切面，像方形/长方形截断），不做圆头、不做收尖**；端头宽 = 臂宽 1.0D；每向最远 **5.0D**（总跨度 10D）。

> 已定值：①脉冲=冲 5.3 → 落回 5.0 → 顶住 → 收 2.5（无回抽段）；②端头**平头/方形**；③地面**不留**任何痕迹。

### 端头细节（按“平头”画）
- 四根糖柱都是**等宽矩形**：宽 1.0D，端面一刀平切，端面与柱身同色，端面比柱身亮 8%（受光面）。
- 端面两侧拐角 **1–2px 极小圆角**（只是防锯齿，肉眼仍是直角）。
- 端头**不加高光点、不加球型收口**（那是圆头，用户明确否掉）。

## 4. 连锁

- 十字命中其他糖泡 → 被命中的泡**立即**进入炸膜阶段（不等它自己的 5 秒）。
- 每颗泡一生只炸一次；被连锁炸掉的泡不再参与连锁（防雪崩）。
- 同一帧内多颗同时命中时，错开 60–90ms 触发，避免同一毫秒一起炸。

## 6. 技术实现（T1）

- **WebGL2 单 quad / 球**，片元着色器里解析球面求交：`r = length(p)`，`z = sqrt(1 - r²)`，法线 `n = vec3(p, z)`。
- **变形**：把屏幕坐标按当前状态的 `scaleY/scaleX/topDip` 逆变换回一个单位球，再做求交——这样压扁/顶部下陷不需要改几何，只改 3 个 uniform。
- **材质**：折射（取背景纹理，IOR 1.42）+ 膜边菲涅尔 + 内部对流（球面坐标双层噪声）+ 顶部压陷处的内壁可见（法线转背面时用背面着色）+ 硬高光（随变形移动）。
- **背景纹理**：一次性烘焙的静态图（不是每帧截图），保证 1 draw call 之外没有额外成本。
- **降级**：无 WebGL2 → Canvas2D 静态球（不折射、不对流，只保留明暗三层与压弹变形）。
