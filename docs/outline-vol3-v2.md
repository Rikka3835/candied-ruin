## 与 ch1–22 的接口（对版清单）

- ch1：老塞的「甜渊」与缺两指 → 卷三 ch33 兑现他的过去。
- ch5：第三人规则（在册试糖人签保）→ ch28 组队时用上（老塞签她）。
- ch7：签名纸被抢 → ch25 三份报告里那份签名纸成为证据。
- ch11：旧蜜掉一格（五→四）→ ch26 再掉一格（四→三）时读者知道这不是第一次。
- ch16：商盟抄件 → ch27 塞拉用它做交易筹码。
- ch21–22：两道封条、罐子在床底 → ch23–24 的引信。
- ch23：蜡是涩的（已被换过）→ ch32 喉道里第二次出现「涩的蜡」。

## 阶与格：本卷怎么露

- 芙兰：灰→白（ch26），格 2（ch26 掉一格后）；台词里会出现「我还剩两格」。
- 琉玥：白→蜜（ch31），代价是右手疤。
- 薇尔：灰→白（ch30），代价是名字。
- 老塞：焦（一生只剩三次记名，ch33 用掉一次）。
- 每章最多出现两处「格」，且必须由人说出来或她自己在心里数，不许叙述报数。
