# 卷一二「章内结构手术」作业说明（2026-10-30）

## 一、这次动什么

卷一二（ch1–22）已经做过一次**逐句重铸**（把短句焊接成长句），句子层面不再动。这次只动**章内结构**，解决三个读者能一眼看出来的问题：

1. **一章只有 2–3 场戏**，靠描写把字数填满 → 拆成 **≥4 场**，场与场之间要有转场。
2. **对话占比过高**（全书均值 49.7%，最高 ch13 76.7%）→ 读起来像剧本/分镜。压到 **≤40%**。
3. **叙述段太碎**（≤40 字的叙述段占 83.4%）→ 并段，叙述短段占比压到 **≤60%**。

## 二、硬指标（每章都要过）

| 指标 | 目标 | 说明 |
|---|---|---|
| 场数 | ≥4 | 一场＝同一时间地点里的一组连续动作/对话 |
| 对话汉字占比 | ≤40% | 现在是 26–77%，均值 49.7% |
| 叙述短段占比（≤40 字） | ≤60% | 现在均值 83.4% |
| 均句长 | 13–16 字 | 现在 10–15 |
| 「她说/他说/我问/他问/她问」 | ≤4 次/千字 | 现在 4.2–19.4，均值 10.9 |
| 破折号 | ≤3 处/章 | |
| 章长 | 原字数 ±10% | 不许为了压对话把戏写丢 |

## 三、怎么拆场（关键做法）

- 不是加情节，是**给已经写出来的事件分段**：一次移动、一次换对象、一次时间跳，就是一场。
- 每场要能回答「这场结束时，什么变了」——信息变了、关系变了、手里多了/少了一样东西、代价付了。写着「什么也没变」的场，要么并进邻场，要么补一拍实动（不许新增剧情事实，只能把已有的动作用具体动作写出来）。
- 转场只写一到两句：时间推进、位置移动、身体状态（手冷、嘴里还留着味）。**禁止用「第二天」「后来」开头连写**，用具体的物和动作带过去。
- 拆场优先找这几类地方：她现在在哪儿、对面是谁、手上拿着什么、她尝到了什么。

## 四、怎么压对话占比（不许删台词内容）

1. **同一人连说的话并成一段**（两句并一段、三句并一段，中间不加空行）。
2. 对话簇之间**插入叙述拍**：她的手在做什么、糖在嘴里化成什么、对面的鞋踩在哪。每个对话簇最多连 6 行，第 7 行前必须有叙述。
3. 删掉多余的「她说/他说」，改成动作替代（「她把勺子放下」「他没抬头」）。
4. 台词**一个字都不许改词**，只能并段、调顺序、加叙述。剧情事实、时间线、伏笔、章末钩全部保持。

## 五、自测怎么跑

```
cd bubble-vanguard-app
python scripts/tmp_struct_scan.py | grep 你的章号
```

输出字段：`han`（汉字）、`mean`（均句）、`narr`（叙述段数）、`nshort`（叙述短段%）、`dial`（对话占比%）、`tags(n/k)`、`dash`（破折号）、`maxp`（最长段）。

## 六、交回来要报什么

每章一行：`章号 | 改前→改后 han | mean | nshort | dial | tags/k | dash | 场数 | 一句话说明拆了哪几场、加了什么转场`。另外单列：**你删掉的重复句/重复动作**（有就写位置，没有写「无」）。
