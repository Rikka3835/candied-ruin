# 芙兰 立绘委托书 v1

用途：小说站《糖渍旧蜜》人物档案页主视觉 + 表情差分（网站公开，需商用授权）
范围：本次只做芙兰一人；不做 Live2D、不做三视图、不做场景

## 1. 画幅与用途

- 画幅：竖幅 3:4，大腿以上（半身到膝）
- 站上用法：档案页卡片 900×1200；点开放大 1800×2400；缩到 300px 宽仍要认得出是芙兰
- 构图要求：人物略偏左、右侧留一点空气（正文标签会压在右边）；头顶留 8–10% 空白
- 背景：透明底；另存一份纯白底

## 2. 角色（原文，可直接给画师）

猫族少女，16 岁，萝莉体型：个子约一百四十八公分，四肢细、肩膀窄，小圆脸带一点婴儿肥，下巴却收得尖。皮肤是偏蜜的白，鼻尖和耳尖常年被晒得发红。眼睛大，琥珀色竖瞳，眼尾略往上挑，睫毛密而短；笑起来露出一颗小虎牙。

黑色短发齐耳，发梢挑染成蜜色。猫耳与尾巴银白色，耳尖带蜜色斑点，耳朵会随声音转向；尾巴末端一点蜜色，蓬松卷曲，比她本人诚实。左耳挂一枚猫牙耳坠，牙尖磨得圆。

米白棉麻短袖衬衫，洗得发软，领口敞开、袖口卷到手肘；外搭蜜糖色旧皮质短马甲，旧铜扣，肩线有缝补痕迹，胸口贴袋装糖晶屑。白色三层棉布短裙，到大腿中段——白是洗旧的白，泛灰，裙摆一块方形补丁，下沿有洗不掉的糖渍黄印。黑色棉质过膝袜，袜口一道蜜色条纹；棕色系带短靴，鞋头磨损。深棕宽皮带配旧铜扣，挂牛皮小袋、铜制小勺、两支蜡封玻璃管、一把旧折叠小刀。颈上细麻绳坠一颗琥珀石，外层包着干透的糖壳。

手小、指头短，指甲剪得秃，指腹一层薄茧；膝盖上有旧擦伤。

性格：表面是只小凶猫，底子是飒的。被戳穿心事耳朵先动，然后竖尾巴装凶；遇事第一个往前站，疼也不哭给人看。
