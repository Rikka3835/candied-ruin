# 对标拆解：daydream7（镜头 vs 结论）

来源：2026-10-28 读完 `https://daydream7.pages.dev/#/read/1` 的序章 + 第一章 5 节，与我们的 `001.md` 同口径统计。这份文件是**写第 3 章及以后要照着改的清单**，不是赏析。

## 同口径数字（我们 vs 他们）

| 指标 | 我们 001 | 他们 ch1 |
|---|---|---|
| 字数 | 2,665 | 1,942–3,194（中位 2,580） |
| 段落中位长 | 21 字 | **13–18.5 字** |
| ≤20 字短段占比 | 47% | **55–77%** |
| 句均长 | 11.1 | 10.1–11.9 |
| **对话段占比** | **43%** | **8–29%** |
| 情绪词 | 1.9 处/千字 | **0.4–1.0** |
| 破折号 | 8 处 | 0–5 处 |
| 每章新出现人名 | 3 | 1 |

结论：**字数与句长同档，差在段长、对话占比、情绪命名密度。**

## 五个差距（每条都带原文）

1. **段末落点**：我们落在判断，他们落在动作。
   我们每约 280 字有一句「金句」（「赊账的人没有资格讲公道」等 9–10 处）；他们 3,194 字只有 3–4 处，其余段末是动作——「他不知道自己为什么擦，手已经动了」。
2. **设定怎么给**：我们让角色口播规则，他们让角色做错。
   玛尔塔讲「商队按低半档收，我按低半档出」是完整的经济课；他们整节没有一句世界规则说明，靠信息缺席造悬念。
3. **对话的功能**：我们交换信息，他们交换空白。
   他们一半对话是「这个切多厚？」「不知道。」——用来展示两人还不熟。
4. **结构性根因**：他们主角是新人（天然可以不解释），我们是内行（她全懂，只能往外倒）。
   解法两条：给芙兰配一个「不懂的人」替读者发问，或让她在关键处「不问、只看」。
5. **情绪**：他们几乎不命名情绪，我们靠判断句代偿，读起来像作者在旁白点评；破折号多也是同源（后面常跟一句补充解释）。

## 三条可执行改法（写第 3 章起执行）

| # | 改法 | 验收判据 |
|---|---|---|
| C1 | 每章「点题句」≤3 处，其余段末改成动作或物件 | 把每段最后一句拎出来，是抽象判断就换 |
| C2 | 短段占比 47%→55%+，段落中位 21→17 字 | 只拆段不删字，字数不变 |
| C3 | 对话段占比 30% 左右（现在 43%） | 把解释性对话改成「她做给你看」或「只报一个数」 |

## 不照搬

- **章末软落幅**：我们规则是「具体威胁或具体代价」，软硬交替即可。
- **第三人称**：芙兰第一人称是骨架，不改。
- **一节只做一件事**：他们 2,580 字只做「到达」；我们不减事件，在事件之间加空镜（一句时间推进、一个物件特写、一次手部动作）。

## 站点层面可借鉴（不急）

- 设定集分「主线 / 个人章 / 设定集」三类，设定 19 条带类型（人物、地点、组织、背景）；
- 每章评论区、留言板、两个小游戏 + 排行榜（提高停留）；
- 章节标题用具体名词（「新港来的青年」「百分之四十的」），与我们「一口的价钱」同路线，已对上。
