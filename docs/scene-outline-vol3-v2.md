## ch23 街心

**本章事件**：三方街心对峙，开罐只验出「脏」；雅各布当众说出「旧蜜」；净火节提前到后天一早；莉娜贴两道封条。

**场 1**｜时间地点：D 夜，街心石板（ch22 最后一句话之后）
- 在场人：芙兰、伊莎贝尔、马蒂亚斯·科尔（商盟主事）、莉娜、老塞（人群后）、玛尔塔（铺窗后）、皮普（人缝）、雅各布（石阶）
- 核心行动：芙兰跪着把罐子放上街心石板，手指一根根离开罐身；伊莎贝尔先伸手搭罐口；马蒂亚斯·科尔从人堆里迈一步，左手银戒指亮一下；三方互不让——教会要验、商盟要认货、行会要销号；莉娜把文书摊在石板上，一张一张抹平，最后用文书一角压住罐底；没人先动。
- 对话要点：
  - 伊莎贝尔→马蒂亚斯：「先验货。」／马蒂亚斯→伊莎贝尔：「商盟的货，先验货。」
  - 伊莎贝尔→马蒂亚斯：「货已经出库了。出库的货，教会先管。」／马蒂亚斯：「出库是商盟的库。」／伊莎贝尔：「库里烧起来，烧的是这条街。」
  - 芙兰→三人：「三样说法。你们先商量好，这罐子归谁。」（正文原句，不可改）
  - 莉娜→三人：「行会还没销号。册子上，它还是货。」／马蒂亚斯：「货也要验。」／伊莎贝尔：「验了也要销。」／莉娜：「销号要人签字。签谁的名。」——没有人答。
  - 芙兰→三人：「你们三个人，谁尝过它？」（正文原句，不可改）——街心静下来，莉娜的笔尖聚墨。
- 本章代价推进：摊子今夜已经停火，封条还没贴，一天三枚半的进项先断了；罐子成了全街的账，谁先伸手谁做主。

**场 2**｜时间地点：同（片刻后）
- 在场人：芙兰、伊莎贝尔、马蒂亚斯、莉娜、围观街坊
- 核心行动：芙兰说「那就我先尝」；指甲刮封蜡——行会封蜡掺松香，涩；罐口这圈蜡软、滑，一推就过去；掀盖；罐里垫旧布，布上只露一个断口，边上有指头压过的凹；她把布往上提了一寸，停住；伊莎贝尔问「罐子里就这些」，她答「就这些」，把布按回原处。教会看见的，只是布上一个断口。
- 对话要点（此场以动作为主，台词少）：
  - 伊莎贝尔→芙兰：「罐子里就这些。」／芙兰→伊莎贝尔：「就这些。」（正文原句，不可改）
  - 伊莎贝尔（对身后收渣的人）→：「盖上。别吹了风。」（可选，正文无）
  - 莉娜（笔尖停在纸上）→芙兰：「再说一遍。就这些？」／芙兰：「就这些。」（可选，正文无）
- 本章代价推进：她没有把布掀开，教会也没有多问——罐子暂时留在她手里，可摊子从今夜起不进货、不接客，三枚半的进项一笔一笔往下掉。

**场 3**｜时间地点：同（紧接）
- 在场人：芙兰、伊莎贝尔、马蒂亚斯、莉娜、街坊
- 核心行动：芙兰用铜勺从断口边缘刮下一片薄得透光的糖；火折子点着，蓝焰舔上去，片子卷了一下，化成一小块黑，塌在勺底；伊莎贝尔接过勺子，凑近闻，闻了很久，鼻子动了两下，又闻一次；她把黑渣倒进三角纸包，压进袖子。
- 对话要点：
  - 伊莎贝尔（闻完）→芙兰：「脏。」（正文原句，不可改）
  - 芙兰→伊莎贝尔：「哪里脏。」
  - 伊莎贝尔→芙兰：「烧完的渣里有旧东西的味道。」
  - 芙兰→伊莎贝尔：「那叫旧衣服。」／伊莎贝尔→芙兰：「那叫脏。」（正文原句，不可改）
  - 莉娜（落笔）→文书：「判：不洁。」
- 本章代价推进：「脏」被装进教会的纸包——她的糖从「待验」变成「脏货」，摊子上的三枚半，跟着一起脏了。

**场 4**｜时间地点：同（话音落下）
- 在场人：芙兰、伊莎贝尔、马蒂亚斯、莉娜、雅各布、皮普、老塞、街坊
- 核心行动：芙兰从断口再刮一片，比刚才还薄，舌尖碰一下，停三下，吐在罐盖里侧；她一层一层报味，莉娜的笔在纸上走；报到第三层，莉娜的笔停了；石阶上缺牙的老头雅各布脱口说出「旧蜜」；伊莎贝尔顶回去；老头说完就走，皮普追出去，追回来只带回一句「他说他小时候闻过。闻过一次」；老塞在人群后开口。
- 对话要点：
  - 芙兰→莉娜（报味，一句一句等对方写完）：「甜是正的。不是新糖的甜，是放久了的甜，甜得很稳，不冲。」／「第二层是霉。不是坏了的霉，是干霉，像纸。」／「第三层——旧衣服。晒过太阳的棉布，收进箱子，压着樟脑，箱底有一点潮。」（正文原句，不可改）
  - 芙兰→莉娜：「不是糖旧了。是收着它的人旧了。」（正文原句，不可改）／莉娜：「『收着它的人』，是谁。」／芙兰：「不知道。舌头只知道旧，不知道是谁。」
  - 马蒂亚斯→伊莎贝尔：「这句话不能上文书。」／伊莎贝尔：「那就不上。只上『脏』。」（正文原句，不可改）
  - 雅各布（看着脚边石头，像跟自己说话）→街心：「旧蜜。」（正文原句，不可改）／伊莎贝尔→雅各布：「没有旧蜜。只有脏糖。」／雅各布→伊莎贝尔：「旧蜜是收着的。脏糖是扔的。」（正文原句，不可改）
  - 莉娜→雅各布：「名字。」／雅各布：「雅各布。」／莉娜：「姓呢。」／雅各布：「不记得了。就记得这个味。」（正文原句，不可改）
  - 老塞（人群后，不高不低）→街心：「这条街上，还有人记得。」（正文原句，不可改）
- 本章代价推进：旧蜜两个字当众落地——她的摊子不再是摊子，是证物；三枚半的进项，从今天起归零。

**场 5**｜时间地点：同（老塞话音落下）
- 在场人：芙兰、伊莎贝尔、马蒂亚斯、莉娜、街坊
- 核心行动：伊莎贝尔不再纠缠罐子，转身面对整条街，宣布净火节提前到后天一早；商盟出车，账走公账；行会出告示；「车上的糖算净化的还是商盟的」当场分账；芙兰问「哪一年的糖」，伊莎贝尔答「今年的」；白蜡珠在袖口里响了一声。
- 对话要点：
  - 伊莎贝尔→整条街：「今年的净火节，提前。后天一早，街心的糖，一并过火。」（正文原句，不可改）
  - 伊莎贝尔→马蒂亚斯：「商盟出车。」／马蒂亚斯：「车出。账走公账。」／伊莎贝尔：「车上的糖，算净化的，还是算商盟的。」／马蒂亚斯：「火烧的那一层算净化的。烧不到的，还是货。」（正文原句）
  - 伊莎贝尔→马蒂亚斯：「烧不到的就不要装上来。」／马蒂亚斯：「装不装，不是我一个人说了算。」／伊莎贝尔：「那你就去问说了算的人。后天一早，车要空着到。」（正文原句）
  - 伊莎贝尔→莉娜：「行会出告示。」／莉娜：「照会。」（正文原句）
  - 芙兰→伊莎贝尔：「哪一年的糖。」／伊莎贝尔→芙兰：「今年的。」（正文原句，不可改）
- 本章代价推进：封条还没贴，先有了日子——后天一早，她摊上的糖、这条街的糖一起过火；三枚半的进项，连日子一起被定了。

**场 6**｜时间地点：D+1 天亮，摊板前
- 在场人：芙兰、莉娜、玛尔塔、皮普、阿芙拉（窗后）
- 核心行动：莉娜带两个杂役来，浆糊罐口还热；第一张封条刷上摊板，第二张贴上糖箱，每个角都按过；玛尔塔从铺子里出来交涉，说箱子是铺子腾的；莉娜说铺子腾的箱子也在册上；玛尔塔回去关窗；阿芙拉开窗看一眼又扣上；皮普问今天还摆不摆；芙兰说摆家里。
- 对话要点：
  - 莉娜（刷封条）→摊板：「四一七批号，申报未讫。摊子暂封。」（封条原文，不可改）
  - 芙兰→莉娜：「封多久。」／莉娜：「核完。」／芙兰：「核到什么时候。」／莉娜：「册子上没写。」（正文原句，不可改）
  - 玛尔塔→莉娜：「莉娜姑娘。她那箱糖，是我铺子里腾出来的。」／莉娜：「铺子腾的箱子，也在册子上。」／玛尔塔：「册子上写她名字，不写我名字。」／莉娜：「写谁的名字，我改不了。」（正文原句）
  - 皮普→芙兰：「姐，那咱今天还摆不摆。」／芙兰：「摆。摆家里。」（正文原句，不可改）／皮普：「摆家里谁买。」／芙兰：「你呀～」（正文原句）
- 本章代价推进：一天三枚半，从「今天不卖」变成「册子上没写多久」——封条贴上去，进项归零成了定局。

**场 7**｜时间地点：同（人散后）
- 在场人：芙兰、老塞
- 核心行动：人都散了，摊板前只剩两张封条和太阳；芙兰蹲下用指甲刮封条边上溢出的蜡，行会蜡涩，指甲缝里嵌进白的；老塞在背后站定，问「开过了」「教会看出什么」；她答「看出脏」；老塞说看出脏就够了，看不出的别自己往外说；他走两步又停下，说她该看一眼说「旧蜜」的老头；她答「我在看伊莎贝尔」；老塞说下回先看说话的人，走了；她抱起罐子。
- 对话要点：
  - 老塞→芙兰：「开过了。」／芙兰：「开过了。」／老塞：「教会看出什么了。」／芙兰：「看出脏。」（正文原句）
  - 老塞→芙兰：「看出脏，就够了。看不出的，别自己往外说。」（正文原句，不可改）
  - 老塞→芙兰：「那老头说旧蜜的时候，你该看他一眼。」／芙兰：「我在看伊莎贝尔。」／老塞：「下回先看说话的人。」（正文原句）
  - 芙兰（抱罐，低声）→自己：「三枚半。」（她的报数口癖，记的是摊子一天的进项）
- 本章代价推进：摊子一天三枚半，封条上没写解封的日子；她把蜡屑抠下来，抠不掉这笔账。
- **本章代价**：摊子一天三枚半的进项，归零。
- **本章钩型**：实动——「这一次，蜡是涩的。」
- **章末落点**：她抱起罐子，罐口那道蜡在手下软、滑；指甲缝里那点蜡屑，涩的。

## ch24 净火节

**本章事件**：净火节烧糖；供糖小箱被推到火边，芙兰闻见人味，手抬到一半没举；教会当场宣布封层令；她当众说「没闻到」；封条贴到井口。

**场 1**｜时间地点：D+2 清早，街心火场
- 在场人：芙兰、玛尔塔、皮普、老塞、琉玥（鉴评所记录）、伊莎贝尔、莉娜、马蒂亚斯·科尔（商盟主事）、街坊
- 核心行动：街心的糖缸堆成火堆，白布揭下来；商盟的车停在火边，车上单独放一只白蜡封口的小木箱，箱盖上没有字，只压了一道商盟的火漆；伊莎贝尔念祷词，火把递上去；街糖先烧，火从底下舔上来；玛尔塔站在人群最前面，两只手在围裙上擦。
- 对话要点：
  - 伊莎贝尔→整条街：「今年的糖，今年的火。烧干净的，才算今年的。」（净火节的口径）
  - 莉娜→伊莎贝尔（照册）：「街糖十三缸，册上已核。」／马蒂亚斯→伊莎贝尔：「供糖一箱，另册。烧的是街糖。」（不可改：供糖走另册）
  - 伊莎贝尔→净化队：「推到火边。」（不可改：供糖被推到火边）
  - 马蒂亚斯→伊莎贝尔：「那是供糖。」／伊莎贝尔→马蒂亚斯：「供糖也是糖。」／马蒂亚斯：「账上不是这么写的。」／伊莎贝尔：「账上改。」
  - 玛尔塔→净化队员：「那两缸是我的。」／净化队员→玛尔塔：「册上写了。两缸。」（玛尔塔的两缸在十三缸里）
- 本章代价推进：街糖先烧，玛尔塔的两缸也在里面；供糖却还停在车边——她盯着那只小箱，箱口的白蜡在火气里发亮。

**场 2**｜时间地点：同（火起后）
- 在场人：芙兰、伊莎贝尔、马蒂亚斯、琉玥、玛尔塔、街坊
- 核心行动：净化队把白蜡小箱从车上抬下来，推到火边；蜡受热，边角化开一线；芙兰站在人前，闻见那股味——铁、咸、烟，和 ch20 第五只瓶子里的味道一样；她的手抬到一半，停住；她没有举，也没有出声；箱子被推进火里，白蜡烧起来，火苗矮了一下，又高了。
- 对话要点：
  - 伊莎贝尔（对火）→净化队：「烧透。别留渣。」
  - 净化队员→伊莎贝尔：「箱子上是白蜡。」／伊莎贝尔：「白蜡也是糖做的。烧。」（为白蜡线埋一句，不点破）
  - 玛尔塔（看着火，低声）→自己：「两缸。」
  - 芙兰（心里，不出声）：「铁。咸。烟。」——她把手放回袖子里。
- 本章代价推进：她闻见了人味，手抬到一半，放下去——这一笔没有证人，先记在她自己身上。

**场 3**｜时间地点：同（火最旺时）
- 在场人：芙兰、伊莎贝尔、莉娜、马蒂亚斯、街坊、琉玥
- 核心行动：伊莎贝尔转身面对整条街，宣布封层令：甜渊各入口，从今日起查封；街坊问为什么；她答「底下有东西上来了」；莉娜当场照会，说封条今日贴到各口；马蒂亚斯想保商盟的库，被顶回去。
- 对话要点：
  - 伊莎贝尔→整条街：「甜渊各入口，从今日起查封。」（不可改）
  - 街坊→伊莎贝尔：「为什么。」／伊莎贝尔：「底下有东西上来了。」（不可改）

## ch29 第一带·锅沿

**场 1**｜时间地点：入井后第一个时辰｜城西废井底·锅沿口石坎
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：井盖在头顶合上，光断。热从脚底漫上来，像站在刚撤火的灶台边。老塞把罩着铜网的鱼油灯挂在撑杆上，先迈下石坎，用杆尾敲地：笃、笃、噗——噗的那块不落杆。芙兰把罐子换到胸前，用摊布角打结；薇尔数人，数到五停住；柯林伸手扶壁，立刻缩回来。
- 对话要点：
  1. 老塞：「脚跟着我。踩亮的地方——亮了，就是壳薄。」
  2. 薇尔：「规矩是——火折子不许点。灯行，明火不行。」
  3. 老塞：「糖粉见明火就炸。这底下，火比刀快。」
  4. 柯林：「这点热，我扛得住。」
  5. 芙兰（闻）：「甜在下面。很近，贴着地。」
- 本章代价推进：队伍知道自己带着什么下来（罐、灯、伤药、绳）；第一笔账先记在「谁走最前」上——老塞的脚。

**场 2**｜时间地点：入井后第二个时辰｜锅沿糖壳坡
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：坡面是半透明的糖壳，底下暗红，像灶膛。芙兰忽然抬手，全队停住。她低头闻，又侧耳；糖壳下有东西擦过去，很轻，像湿布拖过锅底。她抛一粒糖晶屑，屑子落地，坡面某处陷下去又弹回来。她指左边绕。薇尔数步子；柯林把短棍换到右手。
- 对话要点：
  1. 芙兰：「站住。有东西在闻我们。」
  2. 老塞：「闻风的。这一带的舌头。」
  3. 琉玥：「先别说话。」（她蹲下听壳）
  4. 芙兰：「它吃血，不吃糖。别弄破皮。」
  5. 薇尔：「绕过去，十七步。」
- 本章代价推进：绕路十七步——路变长，水囊第一次开；芙兰把这次「闻风」记在心里（她只剩两格，闻一次少一次准头）。

**场 3**｜时间地点：入井后第三个时辰｜旧钩子糖壳桥
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：一道糖壳桥横在热沟上，宽只够一人。沟底糖浆咕嘟翻泡，泡破时溅起甜腥的热气。老塞先过，撑杆在桥面点三下：笃、笃、噗——第三下不实。柯林第二个，走到中间，脚下一软，芙兰一把扣住他后领；罐子从她怀里滑了半寸，她用下巴顶回去。琉玥第三个，薇尔最后。
- 对话要点：
  1. 老塞：「钩子。以前有人在这儿搭过桥。」
  2. 琉玥：「糖在流。桥是自己长的。」
  3. 薇尔：「三个人过去，桥短一寸。」
  4. 柯林：「我先过。我轻。」
  5. 芙兰：「罐子给我。你手空着。」
- 本章代价推进：桥短一寸——退路先于敌人被削掉。他们把「只能往前」这件事踩实了。

**场 4**｜时间地点：入井后第四个时辰｜桥头窄台
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、猎食的小兽（一只）
- 核心行动：柯林殿后。黑暗里扑出一只四足的东西，没有眼睛，嘴裂到耳根，身上沾着干糖壳。柯林挥短棍，棍打在它肩上；它一口咬住他左小臂，拖。芙兰贴舌一退——尝到扑面的血甜，反手把糖晶屑撒进它鼻孔；它甩头。琉玥的银匙从侧面敲在它耳后；老塞的撑杆横着叉住它脖子，把它顶下热沟。沟底一阵翻腾。
- 对话要点：
  1. 柯林：「我没事——」
  2. 芙兰：「你流血了。」
  3. 老塞：「血止住。这一层闻血。」
  4. 琉玥：「它在等血。它不吃糖，等的是血里的糖。」
  5. 芙兰（贴舌后）：「它嘴里有糖。血里有糖。」
- 本章代价推进：柯林左臂见血——队伍第一次流血，账本第一笔落地。

**场 5**｜时间地点：入井后第四个时辰末｜桥头窄台
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：薇尔撕下自己袖口给他扎臂，扎得很紧，柯林咬着牙没出声。血滴在糖壳上，没有摊开，被吸了进去；壳下暗红亮了一下，像灶膛里被吹了一口气。芙兰蹲下，用铜勺刮起一点带血的糖壳放进嘴里——甜里带铁，糖是温的，在舌头上动了一下。老塞看着那点亮光，说带上。
- 对话要点：
  1. 薇尔：「它在喝。」
  2. 柯林：「我拖累你们了。」
  3. 芙兰：「你挡了那一下。账记我头上。」
  4. 老塞：「活的糖。下一层认这个。」
  5. 芙兰：「它认得血。」
- 本章代价推进：血被糖壳喝掉；一块带血的活糖进袋——下一带的门票先付了，用柯林的血。

**场 6**｜时间地点：入井后第五个时辰｜糖壳尽头·向下裂口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：糖壳断出一道向下的裂口，口沿结着白霜。芙兰把带血的糖片贴上去，糖片化开一点，往裂口里侧淌，像指路。她回头，井口的光早没了。底下传来一声很低的「咕」——像一大锅糖翻了个泡，又像什么东西咽了一口。她先伸脚。
- 对话要点：
  1. 老塞：「下。」
  2. 琉玥：「下面在动。」
  3. 芙兰：「它尝到了。」
  4. 薇尔：「罐子抱紧。」
  5. 芙兰（低声，给自己）：「它尝到了。它记住这个味了。」
- 本章代价推进：退路（桥短一寸）＋柯林的血已经落下去；带血的活糖糖片化掉一半，剩下一半是下一层的引子。

**本章代价**：柯林左臂见血（队伍第一次流血）；一块带血的活糖（下一带的门票）；糖壳桥短一寸（退路）。
**钩型**：危机——血滴在糖壳上，下面的东西动了（钩子原话：「它尝到了。」）。
**章末落点**：裂口底下的黑里，那声「咕」又响了一次，比刚才近。
**阶／格露头**：芙兰心里数「闻风用掉一次」——不报数（0 处明数）。

## ch30 第二带·糖霜阶

**场 1**｜时间地点：入井后第五个时辰末｜裂口下·糖霜阶口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：裂口下是一道极长的石阶，阶面覆着白霜，脚一踩就黏，抬脚时「啵」一声。老塞把剩下的活糖片按在阶面上，糖片化开，往右下角淌。柯林左臂吊着，走得慢；琉玥把他的短棍接过去背在自己背上。薇尔开口数阶，只报数，不报别的。
- 对话要点：
  1. 老塞：「糖会指路。跟着它化的边。」
  2. 琉玥：「霜是甜的。别舔。」
  3. 薇尔：「第一阶。第二阶。」（她数得很平）
  4. 柯林：「我能走。」
  5. 芙兰：「你走我后面。手别扶壁。」
- 本章代价推进：活糖片化掉一半——门票在消耗；柯林每走一步都在计息（血已经流了一次）。

**场 2**｜时间地点：入井后第六个时辰｜糖霜阶中段
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：阶侧的霜底下有刻痕。薇尔用指甲刮开一片霜：底下是「号」，浅口、斜刀，一个挨一个，像账页。芙兰摸自己铜印的背面——同一种刻法。刻痕旁边本该有名字的地方，被磨平了。老塞看了一眼，没停脚。
- 对话要点：
  1. 薇尔：「这些是号。」
  2. 芙兰：「跟铜印背面一个刻法。浅口，斜的。」
  3. 老塞：「行会来过。过阶留名，老规矩。」
  4. 琉玥：「名字呢。」
  5. 老塞：「名字在下面。」
- 本章代价推进：他们先知道「要交名字」，才走到名槽——代价先被看见，才落下来。

**场 3**｜时间地点：入井后第六个时辰末｜阶底·白蜡封着的凹槽
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：阶底有一道凹槽，槽口封着一圈老白蜡，蜡边有指甲印。芙兰刮一点蜡放舌尖：甜，甜里有哈喇的尾。薇尔蹲下看蜡色，翻册子，指尖停在一行；老塞用三根手指捻蜡屑，捻得很慢。三个人各说一段，谁也没把话说完。
- 对话要点：
  1. 芙兰：「甜在蜡里。」
  2. 薇尔：「蜡九成，糖一成。账上写过这一笔。」
  3. 老塞：「蜡放久了会哈。糖盖那个味。」
  4. 薇尔：「掺进去的糖，批号是四一七。」
  5. 琉玥：「他们烧糖。自己的蜡里掺糖。」
  6. 芙兰：「所以他们烧的不是脏。是账。」
- 本章代价推进：真相落袋：白蜡掺糖，为盖变质，掺的是教会自己判脏的四一七。三个人各记一段，谁也说不全——这是后面没人信的根。

**场 4**｜时间地点：入井后第七个时辰｜阶底·名槽
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：名槽边的阶面上刻着一行旧规矩：下行者留名。老塞说他的名早押在册上，不欠这一道。琉玥刚要伸手，被薇尔拦住。薇尔从芙兰手里拿回自己的铜徽章，用徽章边角在阶上刻「薇尔」——只有名，没有姓。最后一笔落下，霜从笔画上漫过去，字被喝进去。薇尔的脸白了一瞬，手还在刻。柯林叫她「账房那个」，叫完自己愣住。
- 对话要点：
  1. 薇尔：「规矩是——下行留名。我的名字，册上早就没了。」
  2. 芙兰：「我来。」
  3. 薇尔：「你的名字还要用。」
  4. 老塞：「它收一半。」
  5. 柯林：「账房那个——」
  6. 芙兰：「她叫薇尔。」
- 本章代价推进：薇尔的名字刻上阶、被喝掉一半——本章主账落地。柯林那一句「账房那个」是名字开始滑的第一声。

**场 5**｜时间地点：入井后第七个时辰末｜阶底
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：霜从薇尔刻字的手指爬到手腕，绕成一圈白，像戴了只霜镯子。老塞看了一眼，说「它借了你。白。」薇尔把袖子拉下来盖住那圈白，说册子还在她怀里。芙兰想替她擦，擦不掉，指腹上沾了一层凉。琉玥问她手冷不冷；她说冷，又说走。
- 对话要点：
  1. 老塞：「它借了你。白。」
  2. 薇尔：「白就白。册子还在我怀里。」
  3. 芙兰：「擦不掉？」
  4. 薇尔：「擦不掉。」
  5. 琉玥：「手冷不冷。」
  6. 薇尔：「冷。走。」
- 本章代价推进：霜镯子＝甜渊的借据（灰→白，代价已付）；她开始把袖子拉长——名字少了，人还在。

**场 6**｜时间地点：入井后第八个时辰｜阶底平台·回望
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：他们下到第二层的平台，芙兰回头。阶上「薇尔」两个字只剩半边，另半边像被谁用拇指抹过，切口上的霜是新的。老塞说收了一半，剩下一半是她还剩下的。薇尔没有回头，只说走。芙兰把那半边的样子记在眼里。
- 对话要点：
  1. 芙兰：「你的名字——」
  2. 薇尔：「还在。」
  3. 老塞：「收了一半。剩下一半，是你还剩下的。」
  4. 芙兰：「另外一半呢。」
  5. 薇尔：「走。」
- 本章代价推进：半名字——账没结清，留到卷四；甜渊只收走「册上那一半」，街上还认得她。

**本章代价**：薇尔的名字（册上再没有她；阶上刻名被收走一半）；活糖片化尽（门票用完）；薇尔的铜徽章（刻名时磨掉一个角）。

## ch31 第三带·血管廊

## ch32 第四带·喉道

**场 1**｜时间地点：入井后第十二个时辰｜喉道口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：门后是窄道，壁上有软骨似的环，一环扣一环；说话有回声，回声比原话长。柯林喊了一声「薇——」，回声回来只剩「……尔」，他的嗓子立刻哑了，像被掐了一下。薇尔一把捂住他的嘴，掏出炭笔在纸上写：别说话。全队改成写字、手势、唇语。
- 对话要点：
  1. 柯林：「薇——」
  2. （回声）「……尔。」
  3. 薇尔（纸上）：「说话会被吃掉。」
  4. 老塞（低声）：「一个字，一口。」
  5. 柯林（哑）：「我没事。」
- 本章代价推进：柯林的声音被吃掉一半——全队从此闭嘴；消息只能写、只能看。

**场 2**｜时间地点：入井后第十二个时辰末｜喉道中段·号码壁
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：壁上刻满号，一个挨一个，全是行会的浅口斜刀。每个号旁边都有一个被刮平的名字，刮得最干净的那一行，号是「四一七」。芙兰摸那个号，指腹停住；薇尔在纸上记；老塞不看壁，看路。
- 对话要点：
  1. 薇尔（写）：「号是行会的。」
  2. 老塞（低声）：「名字是它的。」
  3. 芙兰：「那我们是第几个。」
  4. 老塞：「别数。」
  5. 芙兰（摸到四一七）：「这个号，我见过。」
- 本章代价推进：号码壁：他们看见过道的历史——号留下，名字刮掉；芙兰知道自己要交的是什么。

**场 3**｜时间地点：入井后第十三个时辰｜喉道中段·印槽
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：壁上凹进去一个印形的槽，槽口封着蜡——涩，掺松香，指甲一刮起白痕。芙兰用指甲刮了一下，想起封条上那股涩。槽的大小正好是一只铜印。薇尔在纸上写行会条款；写完把纸举给芙兰看。琉玥伸手按住芙兰解绳的手。
- 对话要点：
  1. 薇尔（写）：「在册试糖人过层，以牌为质。一牌引一队。」
  2. 芙兰：「行会的规矩，在这儿管用？」
  3. 老塞：「它认牌，不认人。」
  4. 琉玥（按住她的手）：「想清楚。」
  5. 芙兰：「想清楚了。」
- 本章代价推进：涩蜡＝行会的程序在这里管用；牌能引一队——铜印即将离身。

**场 4**｜时间地点：入井后第十三个时辰末｜印槽前
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：芙兰解下颈上的绳，把铜印按进槽里。槽口的涩蜡软下去，像被体温化开。她必须说一个号给喉道——她说「一百零七」。回声把这三个字拖长、吃掉；印沉进壁里，槽口合拢，蜡面平回去。她脖子上只剩一根空绳，绳结还是热的。
- 对话要点：
  1. 芙兰：「一百零七。」
  2. （回声）「一百……零……」
  3. 薇尔（写）：「它收了。」
  4. 老塞：「走。」
  5. 芙兰（摸空绳）：「印是押的。人是走的。」
- 本章代价推进：铜印 107 沉进壁里——身份的一半押出去；行会册上她还是活人（没销号签字），程序救了她，也把她变成「册上的人、渊里的号」。

**场 5**｜时间地点：入井后第十四个时辰｜喉道后段
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：他们往前走。身后回声忽然叫「芙兰」——不是柯林的哑嗓子，也不是她自己的声音，是从壁里出来的，很近。薇尔在纸上写：别回头。芙兰不答，脚步没停。回声又叫了一声，近了一点，尾音拖着甜。琉玥伸手握住她的手腕，握得很紧。
- 对话要点：
  1. （回声）「芙兰。」
  2. 薇尔（纸上）：「别回头。」
  3. 琉玥（唇语）：「走。」
  4. 老塞（低声）：「它记住你了。」
  5. 芙兰（心里）：「不答。」
- 本章代价推进：回声叫她的名字——名字进了喉道，账转到她头上；她第一次在甜渊里「有名字」。

**场 6**｜时间地点：入井后第十四个时辰末｜喉道尽头
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：窄道忽然开阔，风从前面来，暖、甜、带酸，像掀开一锅放凉的糖浆。回声被留在身后。柯林试着出声，嗓子回来一点，第一句话是「你的印」。芙兰摸脖子上的空绳，说押出去了。薇尔在纸上写：册上还有你。
- 对话要点：
  1. 柯林（哑）：「你的印……」
  2. 芙兰：「押出去了。」
  3. 薇尔（写）：「册上还有你。」
  4. 芙兰：「那就够了。」
  5. 老塞：「前面就是胃囊。」
- 本章代价推进：全队过道；芙兰的印留在喉道；她只剩册上的名字和一根空绳。

**场 7**｜时间地点：入井后第十五个时辰｜喉道出口·胃囊风口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：芙兰第一个跨过喉道口。罐子撞在壁沿上，发出一声闷响，像里面有东西翻了个身。胃囊的壁上有什么动了一下，很远，像一面墙在呼吸。老塞停了一步，说「到了」。
- 对话要点：
  1. 老塞：「到了。」
  2. 芙兰：「这层是什么。」
  3. 老塞：「它以前叫——」（停住）
  4. 芙兰：「叫什么。」
  5. 老塞：「先走路。」
- 本章代价推进：跨进第五带；罐子第一次在下面响——它认得这层。

**本章代价**：铜印 107（沉进喉道壁里）；芙兰的名字进了回声；柯林的嗓子（哑了半程）；全队从此不能出声。
**钩型**：危机——回声里有人叫她的名字（钩子原话：「它记住你了。」）。
**章末落点**：她跨过去时，身后那声「芙兰」停了，像被谁捂住了嘴。
**阶／格露头**：无（本章不报阶、不报格）。

## ch33 第五带·胃囊

  2. 芙兰：「第七位是谁。」
  3. 老塞：「册子上的那个空位。」

  5. 芙兰：「他人呢。」
  6. 老塞：「你觉得呢。」
- 本章代价推进：老塞的过去开账：「第七位」这个名字第一次落地；他知道的不肯全说。

**场 3**｜时间地点：入井后第十六个时辰末｜胃囊·壁画前
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、守层者
- 核心行动：囊腔深处，一个半糖的人形跪坐在一幅壁画前，手里一把刮刀，一下，一下，刮壁上的画。它的背壳是糖，手臂是糖，脸是平的——没有五官，只有被磨平的浅坑。它不攻击。老塞站住，叫它，它抬头，用刮糖一样的声音说话。
- 对话要点：
  1. 老塞：「……还在。」
  2. 守层者：「你带人来了。」
  3. 老塞：「我带人来了。」
  4. 守层者：「名字。」
  5. 老塞：「你还记得你的名字吗。」
  6. 守层者：「……」（刮刀停在壁上）
- 本章代价推进：守层者拦路——不是打，是要一个名字；老塞的记名被逼到手上。

**场 4**｜时间地点：入井后第十七个时辰｜胃囊·壁画前
- 在场人：芙兰、老塞、琉玥、薇尔、柯林、守层者

  1. 老塞（叫名，声音被吸走）

  3. 老塞：「我记不得……跟我下来的人，叫什么了。」
  4. 芙兰：「老塞。」
  5. 老塞：「别扶我。三天。」

**场 5**｜时间地点：入井后第十七个时辰末｜胃囊·壁画前

  4. 老塞：「它自己。」
  5. 芙兰：「第七位，就是这张脸？」
  6. 老塞：「……走。」

**场 6**｜时间地点：入井后第十八个时辰｜胃囊·壁画前

## ch34 无底

**场 1**｜时间地点：入井后第十八个时辰末｜胃囊尽头·向下洞口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：囊壁收成一个向下的洞，洞口结着糖壳，风从下往上吹，冷，带着甜焦味。老塞半边身子靠在撑杆上，三天没到，手不能动；柯林额头发烫；琉玥右手包着布，用左手扶人；薇尔蹲下清点：水囊、干面包、绳。
- 对话要点：
  1. 薇尔：「水剩半囊。面包两块。绳子还剩一截。」
  2. 芙兰：「够回去。」
  3. 琉玥：「老塞不能动手。」
  4. 芙兰：「我知道。」
  5. 老塞：「我没死。走。」
- 本章代价推进：补给清点：半囊水、两块面包、一截绳——可数；全队伤。

**场 2**｜时间地点：入井后第十九个时辰｜无底洞口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：薇尔往洞里丢一块糖，侧耳听；没有落底声。柯林从腰间布带里抽出一张号码纸，丢下去；纸也没有声。芙兰数到三十，停了。老塞说别数了，没有底。风从洞里上来，把灯焰吹得往一边倒。
- 对话要点：
  1. 薇尔（丢糖）：「没有底声。」
  2. 柯林（丢号码纸）：「连纸都没有声。」
  3. 芙兰（数到三十）：「三十。」
  4. 老塞：「别数了。没有底。」
  5. 琉玥：「下面是空的？」
  6. 老塞：「不是空。是深。」
- 本章代价推进：一块糖、一张号码纸扔进洞；「没有底」这件事落地——不是深度，是尺度。

**场 3**｜时间地点：入井后第十九个时辰末｜无底洞口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：洞下面传来声音：搅锅、刮底、糖浆翻沸、勺子碰锅沿；有节奏，一阵一阵，像有人守着火。琉玥听出中间那个停顿——三指挂勺，等糖挂到第三指才起锅。薇尔跟着数拍子。芙兰尝风里的味：甜、焦、旧衣服。罐子在她怀里发烫。
- 对话要点：
  1. 琉玥：「有人在下头熬糖。」
  2. 薇尔：「一直在熬。拍子没乱。」
  3. 芙兰：「甜，焦，旧衣服。」
  4. 老塞：「这个就叫——底。」
  5. 琉玥：「它在等谁。」
  6. 老塞：「等它熬完。」
- 本章代价推进：熬糖声＝下面的东西在「做饭」；罐子发烫——它在应声；全队听见，知道下面不是能打的东西。

**场 4**｜时间地点：入井后第二十个时辰｜无底洞口
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：琉玥说都到这儿了；柯林说他能走；薇尔算账：下去容易，上来没有绳。芙兰看洞，又看老塞的手——三天没到，他动不了。她决定撤，说不是怕，是还没学会怎么下去。老塞没反对，只说下去容易，上来难。
- 对话要点：
  1. 琉玥：「都到这儿了。」
  2. 芙兰：「到这儿，才知道下面不是打的。」
  3. 老塞：「下去容易，上来难。」
  4. 芙兰：「那就先学会怎么上来。」
  5. 柯林：「我听你的。」
  6. 薇尔：「我记下这一笔。没下去。」
- 本章代价推进：决定撤回：把「下去」留成债；补给不再消耗，但全队的伤都带回去。

**场 5**｜时间地点：入井后第二十个时辰末｜胃囊·回程
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：他们沿糖脊往回走。薇尔走在最后，用指甲把来时做的记号一道道抹掉。芙兰问她为什么；她说下面的人不用知道我们来过。柯林走不动，琉玥用左手扶他；老塞靠撑杆，一步一步。罐子还在芙兰怀里。
- 对话要点：
  1. 薇尔：「记号我抹了。」
  2. 芙兰：「为什么。」
  3. 薇尔：「下面的人不用知道我们来过。」
  4. 芙兰：「回去的路呢。」
  5. 薇尔：「我记着。」
  6. 老塞（低声）：「海的那边，也这样。」
- 本章代价推进：来路记号被抹（保护，也让回程只剩薇尔的记忆）；全队伤着往回走。

**场 6**｜时间地点：入井后第二十一个时辰｜无底洞口·回望
- 在场人：芙兰、老塞、琉玥、薇尔、柯林
- 核心行动：芙兰最后一个离开洞口。她回头看了一眼：洞里黑得没有反光，熬糖声还在，一勺，一勺。她把罐子往怀里按紧，对琉玥说下次下去，我们带够糖。琉玥说带够。她说完，洞里的熬糖声停了一拍，像有人听见了。
- 对话要点：
  1. 芙兰：「下次下去，我们带够糖。」
  2. 琉玥：「带够。」
  3. 老塞：「海的那边，也这样。」
  4. 薇尔（低声）：「先上去。」
- 本章代价推进：承诺落地——续篇的账先记下；罐子还在她怀里，底下的东西已经听见她的声音。

**本章代价**：全队伤（柯林发烧、琉玥右手、老塞三天、芙兰空绳）；补给空（半囊水、两块面包、一截绳）；来路记号被抹；罐子还在她怀里。
**钩型**：收束（续篇）——「下次下去，我们带够糖。」
**章末落点**：她说完，洞里的熬糖声停了一拍，像有人听见了；然后，又一勺，一勺，接着熬。
**阶／格露头**：无。
