# BUBBLE VANGUARD · 人物外观描述模板 v1

用途：给绘图 AI（ComfyUI / NovelAI）生成角色定稿图。
规则：**每次生成都用同一段描述，一个字都不换。** 换词＝换人。

---

## 一、十步模板（填的时候按这个顺序）

1. 姓名 / 暂称
2. 种族 / 年龄 / 体型
3. 发型发色
4. 眼睛特征
5. 猫耳猫尾等特殊部件
6. 服装（从上到下）
7. 配件
8. 姿态与表情
9. 整体风格
10. 输出要求（背景、构图、不要什么）

写法要求：
- 颜色说准（不要"浅绿"，要"灰绿色 #8FA98C"）
- 长度说清（齐肩 / 到锁骨 / 过腰）
- 材质提到（粗布 / 皮革 / 羊毛 / 铁）
- 不用"很可爱""有点帅""气质独特"这类虚词

## 五、一致性规则（比描述更重要）

1. 固定模型、固定 LoRA、固定分辨率（建议 832×1216 竖图）。
2. 固定 seed：每个角色记一个 seed，重出时照抄，只改问题局部。
3. 换角色时**只替换「外观段」**，风格段和负面词一个字不改。
4. 每张图存一份参数记录：模型 / LoRA / steps / cfg / sampler / seed。
5. 生成时不要出现"像某某角色"这类话，AI 会直接照那个角色画。

---

## 六、Live2D 的额外要求（出图前就要说清）

1. 纯色背景，不要渐变、不要地影、不要装饰。
2. 人物四周留 10% 空白，不能被裁到。
3. 头发、手臂、披风、尾巴不要和身体糊在一起，边缘要清楚。
4. 先出「完整定稿」，再按部件重绘：前发 / 侧发 / 后发 / 脸 / 眼白 / 瞳孔 / 高光 / 眉 / 嘴 / 身体 / 手臂 / 腿 / 尾巴 / 饰品。
5. 透明背景不等于可分部件。要动起来，必须分层。
