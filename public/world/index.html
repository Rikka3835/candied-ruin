前言

世界是怎么被熬出来的

这本书里的世界是被熬出来的。烧它的火、熬剩下的东西、还有熬它的人，都还在底下。

蜜典 残卷 一页账 六个位子 一座教会 年表

《蜜典》· 卷一 · 第一口

圣蜜都正典 · 每岁净火节当众诵读

太初没有天，没有地，只有一锅。
锅是温的。锅里什么都有：蜜、盐、血、灰，还有来不及成为的东西。
什么都有，就是什么都没有。

有什么俯下身，尝了它一口。
那是世上第一次「甜」。
甜的对面，第一次站出了「不甜」。
于是有了里与外，有了生与死，有了神与人——都是被那一口分出来的。

尝的那一位，舍不得咽，也舍不得吐。
他含着那一口，站了一千年。
一千年里，他的脚陷进锅里，膝陷进锅里，胸口陷进锅里。
最后他把那一口咽了下去。
他的身体，就是整块。

整块从锅里浮起来的那天，世界才有了形状：
外面凉，里面烫；上面是天的白，下面是糖的琥珀。
六位神从那一口里生出来，各守一味。
四位在册：初甜、回甘、尾苦、涩口。
还有两位，一位不肯说出自己的名字，一位没有名字。

此处原有字，为历代抄经人所刮。

六神把整块供在世界正中，叫人来看，叫人不要碰。
人来了。人看了。人哭了——光是看着，舌头就自己发甜。
然后人伸出了手。

第一口被分掉，天塌了一角。
第二口，海退了三里。
第三口，第一次有人饿死在糖堆边上。
到第七口，整块只剩下半颗。
神没有拦。
神也在流口水。

所以世界成了现在这样：
甜是稀的，饿是常的，人是会死的。
每一次尝，都是在向这个世界讨一口它已经没有的东西。
舌头记得甜，身体记得饿。这就是人。

所以，圣蜜都的弟兄姐妹：
要收，要烧，要熬。
把散在四处的甜收回来，把脏的烧干净，把干净的倒回锅里。
等整块重新长齐的那天，世界会重新变甜。
在那一天到来之前，不要停手。

甜必再来。

残卷

旧蜜 · 守密人一脉 · 焦边，火蚀过半

……不是他尝了世界。
是世界尝了他。

批一：此句三本互异，一本作「世界把他咽了下去」。

那一口之后，他没有化成糖。
他是被切开的。
六味，是六道口子。
初甜是嘴，回甘是喉，尾苦是胃，涩口是皮。
剩下两道，一道在掌心，一道在背上。
一道叫水味。
一道叫铁腥。

（以下缺）

他们说要熬一个整块。
锅是现成的。
柴是什么？
柴是会喊的。

批二：此节在净火中焚毁，仅存旁注五行。

最小的那一位不肯下锅。
他说：我们本来就是分下来的，熬回去，也还是分下来的。
他们按住他，熬了七天七夜。
第七夜，锅底裂了。
他没有熬透。
剩下的那一半埋进地里，上面压了一座城。
后来的人管那地方叫地下城，管他叫巨神。
他其实有名字。

（名字处被反复涂改，不可辨。）

批三：涂改的墨，和前文不是同一只手。

所以不要找整块。
整块从来只有半颗。
另外半颗在锅里，还在熬。
你尝到的每一口甜，都是从锅里溢出来的。
你每尝一口，锅就浅一分。

另外半颗不在锅里。
在吃它的人嘴里。

末页，另一只手，墨色很新。

无名氏 · 无年月 · 无落款

  • 六道切口陆
  • 地下城一座，含躯壳壹
  • 旧蜜文明，全族壹

贷方

  • 六味陆
  • 整块半

余额：缺

注

  1. 本账以「尝」为货币。一次尝，付一次。
  2. 尝是先付后知价的买卖。付的时候不知道价，知道价的时候已经付完了。
  3. 试糖人者，本账对账人也。其舌即其印。印尽，人销。六味是账上的名字；街上的人不说六味，说挂勺、回甘、尾上带涩。
  4. 圣蜜都每岁焚糖，记作「回收」。回收不入贷方，只入火耗。
  5. 浮泡商盟每岁售糖，记作「流通」。流通不入贷方，只入私囊。
  6. 以上二项，均不使余额变动。

七、若有人愿替他人尝一口，本账可平。

此条被划去，又在旁边重写了一遍。

结

本账自第一口起记，至今未平。
经手人：不详。
复核：不需要。

余额：半颗

六个位子

四位在册 · 两位被刮掉

初甜蜜主

司 给予 / 第一口

正典至高神，尝者的化身，坐在整块正中。

残卷最先被分食的那一位。

圣蜜都每句祷词的开头。

回甘守忆

司 记忆 / 余味

正典掌史册，记下每一个被尝过的名字。

残卷负责记住被熬的人——所以他闭不上嘴。

老塞在第一章讲的那朵白花。

尾苦记账人

司 代价 / 偿还

正典掌戒律：凡尝必偿。

残卷收账的。从不放过，也从不催。

芙兰每尝一次就少一点的味觉。

涩口持界

司 边界 / 成形

正典掌契约，世界的四角由他按住。

残卷把世界「收住」，不让它散回锅里。

蜜契行会的大门；薇尔那本小册子。

水味无味者不在册

司 空 / 遗忘

正典（此位被刮去，不留一字。）

残卷尝者的另一半。他尝不出任何味道，所以能尝出「没有味道」这件事。

卷四。芙兰彻底失味那天，他第一次出现。不说话，只伸手。

铁腥赤蜜不在册

司 血 / 死 / 器

正典记为被镇压的罪神，无名。

残卷最小的那一位。不肯下锅，被按进去熬了七天七夜，没熬透。剩下的躯干就是地下城。

甜渊七层的墙；粗糖里那股「人的味道」。

另有两件不是神的东西：整块是物件——六神供它，圣蜜都拜它，残卷说它是尸块；地下城也不是建筑，是躯壳，行会只是恰好盖在它脚边。

一座教会

圣蜜都 · 七品教阶 · 只收，不尝

教会在分食纪之后才有。第一批人把糖从火里抢出来，抢完才发现：抢的人比糖多。于是他们立了第一条规矩——甜的，得收回去。

  1. 壹

    蜜座

    教会之首。终身不尝糖。甜要还回去，第一个还的人得是他。

    桌前永远放一碗糖，碗沿有指印，没人见他吃过。

  2. 贰

    三枢机

    收甜院定价，净火院烧糖，守炉院记名。

    三院吵了两百年，只为一句：先收，还是先烧。

  3. 叁

    密使

    外派。可带刀，可进不许尝的城。

    他们是最像信徒的人，也是最不像人的。

  4. 肆

    净化队

    火把、铁钩、白布。烧完念一句：这一口，还给您。

    队里最老的规矩是：不问那桶糖是谁熬的。

  5. 伍

    唱经人

    背整部《蜜典》。错一个字，重学三年。

    他们背得越熟，越不敢想第四节最后那半句。

  6. 陆

    执秤人

    验糖官。用秤，不用舌头。

    教会不信舌头——舌头会为了甜说谎。

  7. 柒

    灰衣

    自愿上缴味觉的人。喝一碗烫糖水，从此尝不出。

    教会说：尝是欠，不尝是还。

卷三 · 第十四节「私尝者，偷甜。」——试糖人是行会发的执照，教会不认。他们靠一件被称为「偷」的事活着。

天 使

一把勺

教会不许给天使造像。圣像上只有一柄勺子，柄上刻一味。三品：切、量、递。神用勺，人用舌。

圣 人

闭嘴的人

封圣的条件只有一条：尝出过真相，并且闭嘴。圣阿黛拉把第一块糖扔进火里；圣布里把舌头留在炉边；圣欧墨记下了第七口，名字被刮掉一半。

尝 女

替全城先尝

每代一名。全城的糖先过她的嘴，才准上桌。她不能说话——舌头要留给尝。这一代的尝女，已经三年没开口。她尝的是合格；街上的人尝的是价钱。

收烧熬

甜必再来

教会不知道的那件事净火院烧掉的「脏糖」里，有一部分是人。他们烧得很干净，干净得像在替谁收尾。

年表

四纪 · 到故事开始为止

  1. 未分纪

    一锅。没有前后，没有名字，也没有谁在看着。

  2. 第一口

    世界被尝出来。有了内外、生死、神人。留下的东西叫整块。

  3. 分食纪

    七口。天塌一角，海退三里，整块只剩半颗。糖从此是稀罕物，也是硬通货。

  4. 立会纪

    分食纪末，第一批人把糖从火里抢出来；抢完才发现抢的人比糖多，于是立下第一条规矩——甜的，得收回去。

  5. 熬神纪

    铁腥入锅，锅底裂。旧蜜文明盛极而亡，地下城成形，「炼人成糖」的工艺第一次被写在纸上。

  6. 糖纪 · 现在

    帕芙利亚。行会收糖，商盟卖糖，圣蜜都烧糖。试糖人是最低的一行——他们替所有人对账，用的是自己的舌头。教会的尝女只剩一名，行会的试糖人却越来越多；同样一份活，一个在神殿里，一个在街边。
